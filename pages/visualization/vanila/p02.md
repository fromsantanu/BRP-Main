
# 📊 **Tutorial - Bar Chart Tutorial in Base R**

We will use a simple dataset of sales across four regions.

### Sample Data

```r
# Create a simple data vector
sales <- c(150, 200, 300, 250)
regions <- c("North", "South", "East", "West")
```

---

## 🔶 **Step 1 — Basic Bar Chart**

Let’s start with the most basic bar chart using `barplot()`.

```r
# Basic bar chart
barplot(sales)
```

---

## 🔶 **Step 2 — Adding Labels**

The bars are drawn, but we don’t know which bar is for which region. Let’s add names.

```r
# Bar chart with names
barplot(sales,
        names.arg = regions)
```

---

## 🔶 **Step 3 — Add Title and Axis Labels**

Add a title and axis labels to make the chart more informative.

```r
# Bar chart with title and axis labels
barplot(sales,
        names.arg = regions,
        main = "Sales by Region",
        xlab = "Region",
        ylab = "Sales (in units)")
```

---

## 🔶 **Step 4 — Adding Colors**

Use colors to make the chart more visually appealing.

```r
# Colored bar chart
barplot(sales,
        names.arg = regions,
        main = "Sales by Region",
        xlab = "Region",
        ylab = "Sales (in units)",
        col = c("skyblue", "lightgreen", "pink", "orange"))
```

---

## 🔶 **Step 5 — Adding Borders**

You can add borders to each bar.

```r
# Bar chart with borders
barplot(sales,
        names.arg = regions,
        main = "Sales by Region",
        xlab = "Region",
        ylab = "Sales (in units)",
        col = c("skyblue", "lightgreen", "pink", "orange"),
        border = "blue")
```

---

## 🔶 **Step 6 — Horizontal Bar Chart**

You can flip the chart horizontally.

```r
# Horizontal bar chart
barplot(sales,
        names.arg = regions,
        main = "Sales by Region",
        xlab = "Sales (in units)",
        ylab = "Region",
        col = "lightblue",
        horiz = TRUE)
```

---

## 🔶 **Step 7 — Adding Numerical Values on Bars**

You can annotate the bars with actual sales values.

```r
# Bar chart with text annotations
bp <- barplot(sales,
              names.arg = regions,
              main = "Sales by Region",
              xlab = "Region",
              ylab = "Sales (in units)",
              col = "lightblue")

# Add text on bars
text(x = bp, y = sales + 10, labels = sales)
```

---

## 🔶 **Step 8 — Grouped Bar Chart**

Let’s say you have data for two years. You can create grouped bars.

```r
# Sample data for two years
sales_2023 <- c(150, 200, 300, 250)
sales_2024 <- c(180, 220, 280, 260)
sales_matrix <- rbind(sales_2023, sales_2024)

# Grouped bar chart
barplot(sales_matrix,
        beside = TRUE,
        names.arg = regions,
        col = c("lightblue", "salmon"),
        main = "Sales Comparison (2023 vs 2024)",
        xlab = "Region",
        ylab = "Sales")

legend("topleft", legend = c("2023", "2024"), fill = c("lightblue", "salmon"))
```

---

## 🔶 **Step 9 — Stacked Bar Chart**

Instead of grouping, you can stack them.

```r
# Stacked bar chart
barplot(sales_matrix,
        beside = FALSE,
        names.arg = regions,
        col = c("lightblue", "salmon"),
        main = "Sales Comparison (2023 vs 2024)",
        xlab = "Region",
        ylab = "Sales")

legend("topleft", legend = c("2023", "2024"), fill = c("lightblue", "salmon"))
```

---

# ✅ **Summary**

* `barplot()` is very flexible in Base R.
* We progressively improved the chart by adding:

  * Labels
  * Title & Axis labels
  * Colors
  * Borders
  * Annotations
  * Grouped & Stacked versions
