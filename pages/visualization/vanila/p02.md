
# 📊 **Tutorial - Bar Chart Tutorial in Base R**

We will use a simple dataset of sales across four regions.

---

## 🔷 **Sample Data**

```r
# Create a simple data vector
sales <- c(150, 200, 300, 250)
regions <- c("North", "South", "East", "West")
```

✅ **Explanation:**

* `sales <- c(150, 200, 300, 250)` creates a numeric vector of sales data.
* `regions <- c("North", "South", "East", "West")` creates a character vector of region names to label bars later.

---

## 🔶 **Step 1 — Basic Bar Chart**

```r
# Basic bar chart
barplot(sales)
```

✅ **Explanation:**

* `barplot(sales)` creates a vertical bar chart using the values in `sales`.
* The bars are plotted in default grey without labels.

---

## 🔶 **Step 2 — Adding Labels**

```r
# Bar chart with names
barplot(sales,
        names.arg = regions)
```

✅ **Explanation:**

* `names.arg = regions` sets labels for each bar using the `regions` vector.

---

## 🔶 **Step 3 — Add Title and Axis Labels**

```r
# Bar chart with title and axis labels
barplot(sales,
        names.arg = regions,
        main = "Sales by Region",
        xlab = "Region",
        ylab = "Sales (in units)")
```

✅ **Explanation:**

* `main = "Sales by Region"` adds a title above the chart.
* `xlab = "Region"` labels the x-axis.
* `ylab = "Sales (in units)"` labels the y-axis.

---

## 🔶 **Step 4 — Adding Colors**

```r
# Colored bar chart
barplot(sales,
        names.arg = regions,
        main = "Sales by Region",
        xlab = "Region",
        ylab = "Sales (in units)",
        col = c("skyblue", "lightgreen", "pink", "orange"))
```

✅ **Explanation:**

* `col = c("skyblue", "lightgreen", "pink", "orange")` sets custom colors for each bar using a vector of color names.

---

## 🔶 **Step 5 — Adding Borders**

```r
# Bar chart with borders
barplot(sales,
        names.arg = regions,
        main = "Sales by Region",
        xlab = "Region",
        ylab = "Sales (in units)",
        col = c("skyblue", "lightgreen", "pink", "orange"),
        border = "blue")
```

✅ **Explanation:**

* `border = "blue"` adds blue borders around each bar to make them stand out.

---

## 🔶 **Step 6 — Horizontal Bar Chart**

```r
# Horizontal bar chart
barplot(sales,
        names.arg = regions,
        main = "Sales by Region",
        xlab = "Sales (in units)",
        ylab = "Region",
        col = "lightblue",
        horiz = TRUE)
```

✅ **Explanation:**

* `horiz = TRUE` changes the orientation of bars from vertical to horizontal.
* The axis labels are switched accordingly.

---

## 🔶 **Step 7 — Adding Numerical Values on Bars**

```r
# Bar chart with text annotations
bp <- barplot(sales,
              names.arg = regions,
              main = "Sales by Region",
              xlab = "Region",
              ylab = "Sales (in units)",
              col = "lightblue")

# Add text on bars
text(x = bp, y = sales + 10, labels = sales)
```

✅ **Explanation:**

* `bp <- barplot(...)` stores the midpoints of each bar in `bp`, needed to position the text.
* `text(x = bp, y = sales + 10, labels = sales)` adds the sales values as text slightly above each bar:

  * `x = bp` specifies horizontal positions.
  * `y = sales + 10` positions text slightly above each bar height.
  * `labels = sales` displays the sales values.

---

## 🔶 **Step 8 — Grouped Bar Chart**

```r
# Sample data for two years
sales_2023 <- c(150, 200, 300, 250)
sales_2024 <- c(180, 220, 280, 260)
sales_matrix <- rbind(sales_2023, sales_2024)

# Grouped bar chart
barplot(sales_matrix,
        beside = TRUE,
        names.arg = regions,
        col = c("lightblue", "salmon"),
        main = "Sales Comparison (2023 vs 2024)",
        xlab = "Region",
        ylab = "Sales")

legend("topleft", legend = c("2023", "2024"), fill = c("lightblue", "salmon"))
```

✅ **Explanation:**

* Two sales vectors for different years are combined row-wise using `rbind()`, creating a matrix.
* `beside = TRUE` plots grouped bars side by side instead of stacking them.
* `col = c("lightblue", "salmon")` sets different colors for each group.
* `legend()` adds a legend:

  * `"topleft"` places the legend at the top left of the chart.
  * `legend = c("2023", "2024")` defines labels.
  * `fill = c("lightblue", "salmon")` matches legend colors with bar colors.

---

## 🔶 **Step 9 — Stacked Bar Chart**

```r
# Stacked bar chart
barplot(sales_matrix,
        beside = FALSE,
        names.arg = regions,
        col = c("lightblue", "salmon"),
        main = "Sales Comparison (2023 vs 2024)",
        xlab = "Region",
        ylab = "Sales")

legend("topleft", legend = c("2023", "2024"), fill = c("lightblue", "salmon"))
```

✅ **Explanation:**

* `beside = FALSE` (default) stacks bars for each region, representing cumulative sales.
* Other parameters are as explained above.
