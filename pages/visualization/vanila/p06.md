
# 📊 **Tutorial - Progressive Box Plot Tutorial in Base R**

We will use the built-in dataset **`mtcars`**.

---

## **Step 0: Loading Data**

```R
# Load the mtcars dataset
data(mtcars)
```

✅ **Explanation:**

* `data(mtcars)` loads the built-in dataset `mtcars` into your environment.
* `mtcars` is a dataframe containing car specifications (mpg, hp, cyl, etc).

---

## **Step 1: Basic Box Plot**

```R
# Create a simple boxplot of 'mpg' (Miles per gallon)
boxplot(mtcars$mpg, main = "Basic Box Plot", ylab = "Miles Per Gallon")
```

✅ **Function:** `boxplot()`
✅ **Arguments:**

* `mtcars$mpg` – The numeric vector to plot (Miles per gallon).
* `main` – Title of the plot.
* `ylab` – Label for the Y-axis.

🔎 **Purpose:** Shows median, quartiles, and outliers for `mpg`.

---

## **Step 2: Grouped Box Plot by a Categorical Variable**

```R
boxplot(mpg ~ cyl, data = mtcars, 
        main = "MPG by Cylinder", 
        xlab = "Number of Cylinders", 
        ylab = "Miles Per Gallon")
```

✅ **Explanation:**

* `mpg ~ cyl` – Formula syntax telling R to plot `mpg` grouped by `cyl` (number of cylinders).
* `data = mtcars` – Specifies the dataframe containing these variables.
* `main`, `xlab`, `ylab` – Adds title and axis labels.

🔎 **Purpose:** Compares distribution of `mpg` across cylinder groups.

---

## **Step 3: Adding Colors**

```R
boxplot(mpg ~ cyl, data = mtcars,
        main = "MPG by Cylinder",
        xlab = "Number of Cylinders",
        ylab = "Miles Per Gallon",
        col = c("lightblue", "lightgreen", "pink"))
```

✅ **New Argument:**

* `col` – Adds fill colors for each box. Accepts a vector of color names (length equal to number of groups).

🔎 **Purpose:** Improves visual distinction among groups.

---

## **Step 4: Adding Notches (Median Comparison)**

```R
boxplot(mpg ~ cyl, data = mtcars,
        main = "MPG by Cylinder (Notched)",
        xlab = "Number of Cylinders",
        ylab = "Miles Per Gallon",
        col = c("lightblue", "lightgreen", "pink"),
        notch = TRUE)
```

✅ **New Argument:**

* `notch = TRUE` – Adds notches to the box around the median. If notches between boxes do not overlap, medians differ significantly at \~95% confidence.

🔎 **Purpose:** For visual median comparison.

---

## **Step 5: Horizontal Box Plot**

```R
boxplot(mpg ~ cyl, data = mtcars,
        main = "Horizontal Box Plot",
        xlab = "Miles Per Gallon",
        ylab = "Number of Cylinders",
        col = c("lightblue", "lightgreen", "pink"),
        notch = TRUE,
        horizontal = TRUE)
```

✅ **New Argument:**

* `horizontal = TRUE` – Displays boxes horizontally instead of vertically.

🔎 **Purpose:** Easier readability when variable names are long or categories numerous.

---

## **Step 6: Adding Custom Borders, Width, and Grid**

```R
boxplot(mpg ~ cyl, data = mtcars,
        main = "Customized Box Plot",
        xlab = "Number of Cylinders",
        ylab = "Miles Per Gallon",
        col = c("lightblue", "lightgreen", "pink"),
        notch = TRUE,
        border = "darkblue",
        boxwex = 0.5)  # Narrower boxes

grid()
```

✅ **New Arguments:**

* `border` – Changes box outline color to "darkblue".
* `boxwex` – Controls box width relative to default (1). Here it is narrower (0.5).

✅ **Function:** `grid()`

* Adds horizontal and vertical grid lines to the plot for easier reading.

🔎 **Purpose:** Enhances aesthetics and clarity.

---

## **Step 7: Overlaying Data Points on Box Plot**

```R
boxplot(mpg ~ cyl, data = mtcars,
        main = "Box Plot with Data Points",
        xlab = "Number of Cylinders",
        ylab = "Miles Per Gallon",
        col = c("lightblue", "lightgreen", "pink"),
        notch = TRUE)

# Overlay individual data points using stripchart
stripchart(mpg ~ cyl, data = mtcars,
           method = "jitter",
           pch = 19,
           col = "darkred",
           vertical = TRUE,
           add = TRUE)
```

✅ **Function:** `stripchart()` overlays data points.
✅ **Arguments:**

* `mpg ~ cyl` – Formula syntax for grouping points.
* `method = "jitter"` – Adds small random noise horizontally to prevent overlapping points.
* `pch = 19` – Plotting character (19 = solid circle).
* `col = "darkred"` – Color of points.
* `vertical = TRUE` – Aligns with boxplot orientation.
* `add = TRUE` – Adds to the existing plot instead of creating a new one.

🔎 **Purpose:** Shows actual data distribution alongside box summary.
