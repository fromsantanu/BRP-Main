
# 📊 **Tutorial - Progressive Box Plot Tutorial in Base R**

We will use the built-in `mtcars` dataset for illustration.

---

### **Step 1: Basic Box Plot**

```R
# Use the built-in dataset
data(mtcars)

# Create a simple boxplot of 'mpg' (Miles per gallon)
boxplot(mtcars$mpg, main = "Basic Box Plot", ylab = "Miles Per Gallon")
```

✅ **Explanation:**

* `boxplot()` creates a basic box plot.
* `main` adds a title.
* `ylab` labels the Y-axis.

---

### **Step 2: Box Plot Grouped by Category**

Let’s visualize `mpg` grouped by `cyl` (number of cylinders).

```R
boxplot(mpg ~ cyl, data = mtcars, 
        main = "MPG by Cylinder", 
        xlab = "Number of Cylinders", 
        ylab = "Miles Per Gallon")
```

✅ **Explanation:**

* The formula `mpg ~ cyl` tells R to group mpg by cylinder count.
* `xlab` adds X-axis label.

---

### **Step 3: Adding Colors**

```R
boxplot(mpg ~ cyl, data = mtcars,
        main = "MPG by Cylinder",
        xlab = "Number of Cylinders",
        ylab = "Miles Per Gallon",
        col = c("lightblue", "lightgreen", "pink"))
```

✅ **Explanation:**

* The `col` parameter adds colors to different groups.

---

### **Step 4: Adding Notches (for Median Comparison)**

```R
boxplot(mpg ~ cyl, data = mtcars,
        main = "MPG by Cylinder (Notched)",
        xlab = "Number of Cylinders",
        ylab = "Miles Per Gallon",
        col = c("lightblue", "lightgreen", "pink"),
        notch = TRUE)
```

✅ **Explanation:**

* `notch = TRUE` adds notches to compare medians — if notches don’t overlap, medians are significantly different.

---

### **Step 5: Horizontal Box Plot**

```R
boxplot(mpg ~ cyl, data = mtcars,
        main = "Horizontal Box Plot",
        xlab = "Miles Per Gallon",
        ylab = "Number of Cylinders",
        col = c("lightblue", "lightgreen", "pink"),
        notch = TRUE,
        horizontal = TRUE)
```

✅ **Explanation:**

* `horizontal = TRUE` flips the orientation.

---

### **Step 6: Adding Custom Axes and Grid**

```R
boxplot(mpg ~ cyl, data = mtcars,
        main = "Customized Box Plot",
        xlab = "Number of Cylinders",
        ylab = "Miles Per Gallon",
        col = c("lightblue", "lightgreen", "pink"),
        notch = TRUE,
        border = "darkblue",
        boxwex = 0.5)  # Narrower boxes

grid()
```

✅ **Explanation:**

* `border` changes the color of box outlines.
* `boxwex` controls the box width.
* `grid()` adds a background grid for better readability.

---

### **Step 7: Overlaying Data Points**

Let’s add individual data points on top of the boxplot:

```R
boxplot(mpg ~ cyl, data = mtcars,
        main = "Box Plot with Data Points",
        xlab = "Number of Cylinders",
        ylab = "Miles Per Gallon",
        col = c("lightblue", "lightgreen", "pink"),
        notch = TRUE)

# Add points (jitter to prevent overlap)
stripchart(mpg ~ cyl, data = mtcars,
           method = "jitter",
           pch = 19,
           col = "darkred",
           vertical = TRUE,
           add = TRUE)
```

✅ **Explanation:**

* `stripchart()` overlays the individual data points.
* `method = "jitter"` adds random noise to spread overlapping points.
* `pch` controls the point shape.

---

# 🔥 **Summary**

| Function           | Purpose                |
| ------------------ | ---------------------- |
| `boxplot()`        | Draw box plot          |
| `col`              | Add color              |
| `notch`            | Show median comparison |
| `horizontal`       | Horizontal orientation |
| `border`, `boxwex` | Customize appearance   |
| `grid()`           | Add grid               |
| `stripchart()`     | Overlay data points    |
