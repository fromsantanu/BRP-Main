

# 📊 **Tutorial - Pie Chart in Base R — A Progressive Approach**

We will use a simple dataset throughout:

```r
# Sample data
categories <- c("A", "B", "C", "D")
values <- c(25, 35, 20, 20)
```

---

## **Step 1: Basic Pie Chart**

```r
pie(values)
```

* ✅ This generates a very simple pie chart with default labels (just percentages).

---

## **Step 2: Adding Labels**

Let's add category names as labels:

```r
pie(values, labels = categories)
```

Now the pie chart shows "A", "B", "C", "D" on the slices.

---

## **Step 3: Add Title**

```r
pie(values, labels = categories, main = "Simple Pie Chart")
```

Now the pie chart has a title.

---

## **Step 4: Add Colors**

We can add colors to make it more attractive.

```r
colors <- c("skyblue", "orange", "lightgreen", "pink")
pie(values, labels = categories, col = colors, main = "Colored Pie Chart")
```

---

## **Step 5: Show Percentage Labels**

We can calculate and show percentages on the chart.

```r
# Calculate percentages
percentages <- round(values / sum(values) * 100)

# Create labels with percentages
labels_with_pct <- paste(categories, percentages, "%")

# Plot with percentage labels
pie(values, labels = labels_with_pct, col = colors, main = "Pie Chart with Percentages")
```

---

## **Step 6: Explode Slices (Pull out one slice)**

Use the `explode` effect with the `pie` function via `init.angle` and some creative values.

Actually, in base R, there is no built-in explode parameter, but we can simulate using `clockwise` and `angle` adjustments, or manually modify values (not very common).
A better trick is using the `radius` argument (only available in some R versions).

Another way is using the `plotrix` package:

```r
# Install if not already installed
install.packages("plotrix")
library(plotrix)

# Exploded pie chart
pie3D(values, labels = labels_with_pct, explode = 0.1, col = colors, main = "Exploded Pie Chart")
```

✅ Although this is not strictly "base R", `plotrix::pie3D()` is a common extension people use.

---

## **Step 7: Refine Labels with Legend**

Instead of cluttering the pie chart, we can keep it clean and add a legend:

```r
pie(values, labels = NA, col = colors, main = "Pie Chart with Legend")
legend("topright", legend = labels_with_pct, fill = colors)
```

---

## **Step 8: Start Angle and Clockwise**

Change the start angle or reverse direction:

```r
pie(values, labels = labels_with_pct, col = colors, main = "Customized Start Angle", clockwise = TRUE, init.angle = 90)
```

---

## **Step 9: Advanced Look (Shadow effect simulation)**

We can simulate shadows manually by overlaying two pie charts:

```r
# Draw shadow first (bigger radius)
pie(values, labels = NA, col = adjustcolor(colors, alpha.f = 0.5), radius = 1.1, border = NA)

# Draw actual pie chart on top
par(new = TRUE)
pie(values, labels = labels_with_pct, col = colors, main = "Pie Chart with Shadow")
```
