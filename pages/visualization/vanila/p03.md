

# 📊 **Tutorial - Pie Chart in Base R — A Progressive Approach**


We will use this **sample data**:

```r
# Sample data
categories <- c("A", "B", "C", "D")
values <- c(25, 35, 20, 20)
```

✔️ **Explanation:**
We created two vectors – `categories` holds labels for each group, and `values` holds their numeric values.

---

## **Step 1: Basic Pie Chart**

```r
pie(values)
```

✔️ **Explanation:**
The `pie()` function creates a pie chart using the `values` vector.
By default, it only shows percentages on each slice, without specific category labels.

---

## **Step 2: Adding Labels**

```r
pie(values, labels = categories)
```

✔️ **Explanation:**
The `labels = categories` argument tells R to display each category name (A, B, C, D) on the respective slice instead of only percentages.

---

## **Step 3: Add Title**

```r
pie(values, labels = categories, main = "Simple Pie Chart")
```

✔️ **Explanation:**
The `main` parameter adds a **title** to the chart for easy interpretation.

---

## **Step 4: Add Colors**

```r
colors <- c("skyblue", "orange", "lightgreen", "pink")
pie(values, labels = categories, col = colors, main = "Colored Pie Chart")
```

✔️ **Explanation:**

* `col = colors` sets specific colors for each slice, using a vector of color names.
* This makes the chart visually attractive and helps differentiate slices clearly.

---

## **Step 5: Show Percentage Labels**

```r
# Calculate percentages
percentages <- round(values / sum(values) * 100)

# Create labels with percentages
labels_with_pct <- paste(categories, percentages, "%")

# Plot with percentage labels
pie(values, labels = labels_with_pct, col = colors, main = "Pie Chart with Percentages")
```

✔️ **Explanation:**

* `percentages <- round(values / sum(values) * 100)` calculates the percentage contribution of each value and rounds it to the nearest integer.
* `paste(categories, percentages, "%")` combines the category name with its percentage (e.g., "A 25%").
* We use this `labels_with_pct` as labels for slices to display both name and percentage.

---

## **Step 6: Exploded Pie Chart (3D effect)**

```r
# Install if not already installed
install.packages("plotrix")
library(plotrix)

# Exploded pie chart
pie3D(values, labels = labels_with_pct, explode = 0.1, col = colors, main = "Exploded Pie Chart")
```

✔️ **Explanation:**

* `plotrix` package provides additional plotting functions like `pie3D()` to create **3D pie charts with explode effect**.
* `explode = 0.1` slightly separates each slice from the center for emphasis.
* `col`, `labels`, and `main` work similarly as in base `pie()` function.

---

## **Step 7: Refine with Legend**

```r
pie(values, labels = NA, col = colors, main = "Pie Chart with Legend")
legend("topright", legend = labels_with_pct, fill = colors)
```

✔️ **Explanation:**

* `labels = NA` removes labels from the slices for a cleaner look.
* `legend()` adds a legend box to the plot.

  * `"topright"` specifies the location of the legend box.
  * `legend = labels_with_pct` provides the text for each category with percentage.
  * `fill = colors` shows colored boxes next to each label matching the slice color.

---

## **Step 8: Start Angle and Clockwise Direction**

```r
pie(values, labels = labels_with_pct, col = colors, main = "Customized Start Angle", clockwise = TRUE, init.angle = 90)
```

✔️ **Explanation:**

* `clockwise = TRUE` makes the chart slices progress in a clockwise direction (default is counterclockwise).
* `init.angle = 90` sets the starting angle to **90 degrees**, meaning the first slice will start from the top (12 o’clock position).

---

## **Step 9: Simulate Shadow Effect**

```r
# Draw shadow first (bigger radius)
pie(values, labels = NA, col = adjustcolor(colors, alpha.f = 0.5), radius = 1.1, border = NA)

# Draw actual pie chart on top
par(new = TRUE)
pie(values, labels = labels_with_pct, col = colors, main = "Pie Chart with Shadow")
```

✔️ **Explanation:**

* We first draw a **shadow pie chart** using `adjustcolor(colors, alpha.f = 0.5)` to make it slightly transparent and a larger `radius = 1.1`.
* `border = NA` removes borders.
* `par(new = TRUE)` allows overlaying the next plot on top.
* Finally, we draw the main pie chart over the shadow to create a subtle 3D shadow effect.

# ✅ **Summary Table**

| Feature               | Explanation                                               |
| --------------------- | --------------------------------------------------------- |
| `pie()`               | Basic pie chart function in base R.                       |
| `labels`              | Adds category names or custom labels to slices.           |
| `main`                | Adds a title to the chart.                                |
| `col`                 | Defines slice colors.                                     |
| Calculate percentages | Shows data contribution clearly.                          |
| `paste()`             | Combines text and numeric labels.                         |
| `legend()`            | Adds a color-coded legend for readability.                |
| `init.angle`          | Sets starting angle for first slice.                      |
| `clockwise`           | Changes slice drawing direction.                          |
| `plotrix::pie3D()`    | Creates 3D exploded pie charts (extension beyond base R). |
| `par(new=TRUE)`       | Allows overlaying multiple plots on the same chart.       |
