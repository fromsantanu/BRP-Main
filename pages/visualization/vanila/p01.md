
# 📊 **Tutorial - Line Plot in Base R — A Step-by-Step Approach**

---

### **Step 1 — Create Some Sample Data**

Let’s create a simple dataset to work with:

```r
# Create sample data
x <- 1:10
y <- c(3, 5, 4, 6, 8, 7, 10, 12, 11, 13)
```

Here, `x` is our independent variable (e.g., time, sequence, etc.) and `y` is the dependent variable.

---

### **Step 2 — Basic Line Plot**

The simplest way to create a line plot:

```r
# Basic Line Plot
plot(x, y, type = "l")
```

* `type = "l"` means "line" (if you omit it, R will create a scatter plot by default).

---

### **Step 3 — Add Points to Line**

Add points to make the plot more informative:

```r
# Line plot with points
plot(x, y, type = "b")
```

* `type = "b"` means both **points and lines**.

---

### **Step 4 — Add Titles and Labels**

Make the plot more readable:

```r
# Add titles and labels
plot(x, y, type = "b",
     main = "Simple Line Plot",
     xlab = "X Values",
     ylab = "Y Values")
```

---

### **Step 5 — Customize Line and Point Appearance**

Change color, point type, line type, and width:

```r
# Customize appearance
plot(x, y, type = "b",
     main = "Customized Line Plot",
     xlab = "X Values",
     ylab = "Y Values",
     col = "blue",         # Line color
     pch = 19,             # Point character (solid circle)
     lty = 2,              # Line type (dashed)
     lwd = 2)              # Line width
```

* `pch` controls point symbols.
* `lty` controls line types (1 = solid, 2 = dashed, etc.).
* `lwd` controls line width.

---

### **Step 6 — Add Grid Lines**

Grid lines help to improve readability:

```r
# Add grid
plot(x, y, type = "b",
     main = "Line Plot with Grid",
     xlab = "X Values",
     ylab = "Y Values",
     col = "blue", pch = 19, lty = 1, lwd = 2)
grid()
```

---

### **Step 7 — Add Multiple Lines**

Now, let’s say we have another data series:

```r
# Add a second data series
y2 <- c(2, 4, 3, 5, 7, 6, 9, 11, 10, 12)

# Plot first line
plot(x, y, type = "b", col = "blue", pch = 19, lty = 1, lwd = 2,
     xlab = "X Values", ylab = "Y Values", main = "Multiple Lines")

# Add second line
lines(x, y2, type = "b", col = "red", pch = 17, lty = 2, lwd = 2)

# Add legend
legend("topleft", legend = c("Series 1", "Series 2"),
       col = c("blue", "red"), pch = c(19, 17), lty = c(1, 2))
```

* `lines()` function allows you to add new series to an existing plot.
* `legend()` adds a legend to distinguish the series.

---

### **Step 8 — Control Plot Limits (Axes)**

Control the axis range explicitly:

```r
plot(x, y, type = "b", col = "blue", pch = 19, lty = 1, lwd = 2,
     xlab = "X Values", ylab = "Y Values", main = "Controlled Axes",
     ylim = c(0, 15), xlim = c(0, 12))  # Set y-axis and x-axis limits

lines(x, y2, type = "b", col = "red", pch = 17, lty = 2, lwd = 2)
legend("topleft", legend = c("Series 1", "Series 2"),
       col = c("blue", "red"), pch = c(19, 17), lty = c(1, 2))
grid()
```

---

### **Step 9 — Final Touch: Background, Box, and Minor Tweaks**

Make the plot even nicer:

```r
# Final refined plot
plot(x, y, type = "b", col = "darkgreen", pch = 16, lty = 1, lwd = 2,
     xlab = "Time", ylab = "Measurements", main = "Fully Customized Line Plot",
     ylim = c(0, 15), xlim = c(0, 12), bg = "lightyellow")

lines(x, y2, type = "b", col = "purple", pch = 17, lty = 3, lwd = 2)
legend("topleft", legend = c("Measurement A", "Measurement B"),
       col = c("darkgreen", "purple"), pch = c(16, 17), lty = c(1, 3), bty = "n")
grid()
box()
```

* `bty = "n"` removes legend box.
* `box()` ensures a nice border.
* You can also change `par(bg = "lightyellow")` to set full plot background.
