
# 🟢 **Tutorial - Progressive Scatter Plot Tutorial in Base R**


## **Step 1 — Create Sample Data**

```R
set.seed(123)  # Sets seed for random number generator for reproducibility
x <- rnorm(50, mean = 50, sd = 10)
# Generates 50 random numbers from a normal distribution with mean 50 and sd 10

y <- 2 * x + rnorm(50, mean = 0, sd = 15)
# Creates y as approximately twice x plus some random noise with mean 0 and sd 15

head(data.frame(x, y))
# Shows the first 6 rows of a data frame combining x and y for quick inspection
```

✔ **Explanation:**

* `set.seed()` ensures same random results every run.
* `rnorm(n, mean, sd)` generates `n` normal random variables.
* `data.frame()` combines x and y into a table-like structure.
* `head()` displays the first few rows.

---

## **Step 2 — Basic Scatter Plot**

```R
plot(x, y)
```

✔ **Explanation:**

* `plot(x, y)` creates a scatter plot with `x` on the x-axis and `y` on the y-axis using default settings.

---

## **Step 3 — Add Labels and Title**

```R
plot(x, y,
     main = "Scatter Plot of Y vs X", # adds main title
     xlab = "X values",               # x-axis label
     ylab = "Y values")               # y-axis label
```

✔ **Explanation of arguments:**

* `main`: Sets the plot title.
* `xlab`: Sets label for the x-axis.
* `ylab`: Sets label for the y-axis.

---

## **Step 4 — Improve Appearance (Colors, Point Type, Size)**

```R
plot(x, y,
     main = "Scatter Plot of Y vs X",
     xlab = "X values",
     ylab = "Y values",
     col = "blue",     # sets color of points to blue
     pch = 19,         # sets plotting character; 19 = solid circle
     cex = 1.5)        # controls point size; >1 makes points bigger
```

✔ **Explanation of additional arguments:**

* `col`: Color of the plotted points.
* `pch`: Plotting character code (e.g. 1=open circle, 19=solid circle).
* `cex`: Character expansion factor (controls size of points or text).

---

## **Step 5 — Add Gridlines**

```R
plot(x, y,
     main = "Scatter Plot with Gridlines",
     xlab = "X values",
     ylab = "Y values",
     col = "darkgreen",
     pch = 16,
     cex = 1.3)

grid()
```

✔ **Explanation:**

* `grid()`: Adds gridlines to the current plot for better readability.
* `pch = 16`: Another solid circle plotting character.

---

## **Step 6 — Add Regression Line**

```R
plot(x, y,
     main = "Scatter Plot with Regression Line",
     xlab = "X values",
     ylab = "Y values",
     col = "purple",
     pch = 16)

model <- lm(y ~ x)          # fits linear model y = a + bx
abline(model, col = "red", lwd = 2)
# draws a straight line based on model with red color and line width 2
```

✔ **Explanation:**

* `lm(y ~ x)`: Fits a linear regression model with `y` as dependent and `x` as independent variable.
* `abline(model)`: Adds a line based on the coefficients from `model`.
* `lwd`: Line width.

---

## **Step 7 — Add Text Labels for Points**

```R
plot(x, y,
     main = "Scatter Plot with Labels",
     xlab = "X values",
     ylab = "Y values",
     col = "orange",
     pch = 19)

text(x[1:10], y[1:10], labels = 1:10, pos = 4, cex = 0.8)
```

✔ **Explanation:**

* `text(x, y, labels)`: Adds text labels to specified coordinates.
* `labels = 1:10`: Labels points with numbers 1 to 10.
* `pos = 4`: Positions text to the right of the point (1=below, 2=left, 3=above, 4=right).
* `cex`: Size of text labels.

---

## **Step 8 — Add Legend**

```R
plot(x, y,
     main = "Scatter Plot with Legend",
     xlab = "X values",
     ylab = "Y values",
     col = "blue",
     pch = 19)

abline(model, col = "red", lwd = 2)

legend("topleft",
       legend = c("Data Points", "Regression Line"),
       col = c("blue", "red"),
       pch = c(19, NA),   # NA used when no symbol for line
       lty = c(NA, 1),    # line type; NA for no line, 1 for solid line
       lwd = c(NA, 2),    # line width
       bty = "n")         # removes box around legend
```

✔ **Explanation:**

* `legend(location, ...)` adds a legend.
* `pch`: Points symbol in legend.
* `lty`: Line type in legend.
* `lwd`: Line width in legend.
* `bty`: Box type; `"n"` removes border.

---

## **Step 9 — Advanced: Highlight Subgroups**

```R
group <- ifelse(y > mean(y), "Above Mean", "Below Mean")
# creates a group variable based on y values above or below the mean

colors <- ifelse(group == "Above Mean", "green", "red")
# assigns color based on group

plot(x, y,
     main = "Scatter Plot with Subgroups",
     xlab = "X values",
     ylab = "Y values",
     col = colors,
     pch = 19)

legend("bottomright",
       legend = c("Above Mean", "Below Mean"),
       col = c("green", "red"),
       pch = 19)
```

✔ **Explanation:**

* `ifelse(condition, value_if_true, value_if_false)`: Vectorized conditional operation.
* Here it assigns `"Above Mean"` or `"Below Mean"` to each y value, and maps colors accordingly.

---

### **🔑 Key Takeaways**

✅ **`plot()`** is versatile in Base R for quick scatter plotting.
✅ **`abline()`**, **`text()`**, **`legend()`**, and **`grid()`** enhance interpretability.
✅ **`lm()`** adds regression fitting capabilities.
