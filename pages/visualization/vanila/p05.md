
# 🟢 **Tutorial - Progressive Scatter Plot Tutorial in Base R**

---

### **Step 1 — Create Sample Data**

First, let’s create some simple data:

```R
# Sample data
set.seed(123)  # for reproducibility
x <- rnorm(50, mean = 50, sd = 10)
y <- 2 * x + rnorm(50, mean = 0, sd = 15)

# Quick look at data
head(data.frame(x, y))
```

---

### **Step 2 — Basic Scatter Plot**

Now, let's make a very basic scatter plot using `plot()` function.

```R
# Basic scatter plot
plot(x, y)
```

✅ This gives us a simple scatter plot with default settings.

---

### **Step 3 — Add Labels and Title**

Let’s make it a bit more informative:

```R
plot(x, y,
     main = "Scatter Plot of Y vs X",
     xlab = "X values",
     ylab = "Y values")
```

---

### **Step 4 — Improve Appearance (Colors, Point Type, Size)**

You can customize color (`col`), point type (`pch`), and size (`cex`):

```R
plot(x, y,
     main = "Scatter Plot of Y vs X",
     xlab = "X values",
     ylab = "Y values",
     col = "blue",
     pch = 19,
     cex = 1.5)
```

* `pch = 19` gives solid circles.
* `cex` controls point size.

---

### **Step 5 — Add Gridlines**

Adding gridlines makes it easier to read:

```R
plot(x, y,
     main = "Scatter Plot with Gridlines",
     xlab = "X values",
     ylab = "Y values",
     col = "darkgreen",
     pch = 16,
     cex = 1.3)
grid()
```

---

### **Step 6 — Add Regression Line**

Often, we want to see the trend by adding a fitted line:

```R
plot(x, y,
     main = "Scatter Plot with Regression Line",
     xlab = "X values",
     ylab = "Y values",
     col = "purple",
     pch = 16)

# Fit a linear model
model <- lm(y ~ x)
abline(model, col = "red", lwd = 2)
```

---

### **Step 7 — Add Text Labels for Points**

Sometimes we want to label the points:

```R
plot(x, y,
     main = "Scatter Plot with Labels",
     xlab = "X values",
     ylab = "Y values",
     col = "orange",
     pch = 19)

# Add text labels (just first 10 to avoid clutter)
text(x[1:10], y[1:10], labels = 1:10, pos = 4, cex = 0.8)
```

---

### **Step 8 — Add Legend**

Let’s add a legend to explain the colors or shapes:

```R
plot(x, y,
     main = "Scatter Plot with Legend",
     xlab = "X values",
     ylab = "Y values",
     col = "blue",
     pch = 19)

abline(model, col = "red", lwd = 2)
legend("topleft",
       legend = c("Data Points", "Regression Line"),
       col = c("blue", "red"),
       pch = c(19, NA),
       lty = c(NA, 1),
       lwd = c(NA, 2),
       bty = "n")
```

---

### **Step 9 — Advanced: Highlight Subgroups**

Suppose we want to color code based on a condition:

```R
group <- ifelse(y > mean(y), "Above Mean", "Below Mean")
colors <- ifelse(group == "Above Mean", "green", "red")

plot(x, y,
     main = "Scatter Plot with Subgroups",
     xlab = "X values",
     ylab = "Y values",
     col = colors,
     pch = 19)

legend("bottomright",
       legend = c("Above Mean", "Below Mean"),
       col = c("green", "red"),
       pch = 19)
```

---

✅ **You have now created a fully customized Scatter Plot using only Base R!**
