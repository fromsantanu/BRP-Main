
# 🎯 **Tutorial - Progressive Heatmap Tutorial in Base R**

## **Step 1: Create Some Sample Data**

```R
# Create a sample matrix
set.seed(123)
data_matrix <- matrix(rnorm(25, mean=10, sd=5), nrow=5, ncol=5)

# Add row and column names
rownames(data_matrix) <- paste("Row", 1:5)
colnames(data_matrix) <- paste("Col", 1:5)

# View data
print(data_matrix)
```

### **Explanation:**

* `set.seed(123)`: Ensures reproducibility by setting a seed for random number generation.
* `rnorm(25, mean=10, sd=5)`: Generates 25 random numbers from a normal distribution with mean = 10 and standard deviation = 5.
* `matrix(..., nrow=5, ncol=5)`: Reshapes the 25 random numbers into a 5x5 matrix.
* `rownames()` and `colnames()`: Assign readable names to rows and columns for clarity in the heatmap.

---

## **Step 2: Basic Heatmap using `heatmap()`**

```R
# Basic heatmap
heatmap(data_matrix)
```

### **Explanation:**

* `heatmap()`: Base R function to create a heatmap.

  * By default, it:

    * Clusters rows and columns hierarchically.
    * Scales data by rows (`scale = "row"` by default).
    * Uses a standard heat color palette (yellow to red).

---

## **Step 3: Remove Clustering (Show Pure Data)**

```R
# Heatmap without clustering
heatmap(data_matrix, Rowv = NA, Colv = NA, scale = "none")
```

### **Explanation:**

* `Rowv = NA`: Turns off hierarchical clustering for rows.
* `Colv = NA`: Turns off hierarchical clustering for columns.
* `scale = "none"`: Prevents scaling. By default, rows are scaled to have mean 0 and SD 1; setting to "none" displays raw values.

---

## **Step 4: Change Color Palette**

### **Using predefined palette:**

```R
# Heatmap with custom colors
heatmap(data_matrix, Rowv = NA, Colv = NA, scale = "none", col = heat.colors(10))
```

* `col = heat.colors(10)`:

  * Uses the `heat.colors()` function to generate a vector of 10 colors ranging from red to yellow.

### **Using custom color gradient:**

```R
# Custom palette
my_palette <- colorRampPalette(c("blue", "white", "red"))(20)

heatmap(data_matrix, Rowv = NA, Colv = NA, scale = "none", col = my_palette)
```

* `colorRampPalette(c("blue", "white", "red"))(20)`:

  * Creates a smooth color gradient from blue → white → red with 20 intermediate shades for finer resolution.

---

## **Step 5: Add Title and Adjust Margins**

```R
# Heatmap with titles and adjusted margins
heatmap(data_matrix, Rowv = NA, Colv = NA, scale = "none", 
        col = my_palette, 
        main = "My Customized Heatmap",
        margins = c(5, 10))  # (bottom, left)
```

### **Explanation:**

* `main = "My Customized Heatmap"`: Adds a title to the plot.
* `margins = c(5, 10)`:

  * Adjusts plot margins for axis labels and title.
  * First value = bottom margin (x-axis labels), second = left margin (y-axis labels).

---

## **Step 6: Using `image()` for Custom Annotations**

```R
# Use image() for full control
image(1:5, 1:5, data_matrix, col = my_palette, axes = FALSE, main = "Heatmap via image()")

# Add axis labels
axis(1, at = 1:5, labels = colnames(data_matrix))
axis(2, at = 1:5, labels = rev(rownames(data_matrix)))  # reverse row order

# Add text annotations
for (i in 1:5) {
  for (j in 1:5) {
    text(j, 6-i, round(data_matrix[i, j], 1))
  }
}
```

### **Explanation:**

* `image(x, y, z, ...)`:

  * Creates a heatmap-like image.
  * `x = 1:5`: X-axis positions.
  * `y = 1:5`: Y-axis positions.
  * `z = data_matrix`: Data to plot.
* `axes = FALSE`: Suppresses default axes.
* `main`: Adds plot title.
* `axis()`:

  * Adds custom axes.
  * `at`: Tick mark positions.
  * `labels`: Labels for ticks.
  * `rev()` reverses row labels to match top-bottom orientation.
* `text(x, y, labels)`:

  * Adds text at specified (x, y) positions.
  * Here, `round(data_matrix[i, j], 1)` rounds each value to 1 decimal place.
  * Note: Row indices are adjusted to align correctly (`6-i`) due to image() plotting orientation.

---

## **Step 7: Save the Heatmap**

```R
# Save as PNG
png("heatmap.png", width=600, height=600)
heatmap(data_matrix, Rowv = NA, Colv = NA, scale = "none", col = my_palette, main = "Saved Heatmap")
dev.off()
```

### **Explanation:**

* `png("heatmap.png", width=600, height=600)`:

  * Opens a PNG device to save the plot as an image file.
  * `width` and `height`: Image dimensions in pixels.
* `dev.off()`:

  * Closes the graphics device, finalising the file saving.
