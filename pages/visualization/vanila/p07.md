
# 🎯 **Tutorial - Progressive Heatmap Tutorial in Base R**

---

## **Step 1: Create Some Sample Data**

First, we need some data to plot. We'll create a simple matrix of numeric values.

```R
# Create a sample matrix
set.seed(123)
data_matrix <- matrix(rnorm(25, mean=10, sd=5), nrow=5, ncol=5)

# Add row and column names
rownames(data_matrix) <- paste("Row", 1:5)
colnames(data_matrix) <- paste("Col", 1:5)

# View data
print(data_matrix)
```

---

## **Step 2: Basic Heatmap using `heatmap()`**

Base R provides a very simple function called `heatmap()`.

```R
# Basic heatmap
heatmap(data_matrix)
```

✅ You already get:

* Dendrogram (clustering)
* Default color gradient

---

## **Step 3: Remove Clustering (Just Plot the Heatmap)**

By default, `heatmap()` clusters rows and columns. If you just want a simple heatmap:

```R
# Heatmap without clustering
heatmap(data_matrix, Rowv = NA, Colv = NA, scale = "none")
```

* `Rowv = NA` and `Colv = NA` turn off dendrograms.
* `scale = "none"` prevents scaling the data.

---

## **Step 4: Change Color Palette**

The default colors may not always be ideal. We can customize colors using `heat.colors()`, `terrain.colors()`, `topo.colors()`, or `colorRampPalette()` for more control.

```R
# Heatmap with custom colors
heatmap(data_matrix, Rowv = NA, Colv = NA, scale = "none", col = heat.colors(10))
```

Or using a smoother gradient:

```R
# Custom palette
my_palette <- colorRampPalette(c("blue", "white", "red"))(20)

heatmap(data_matrix, Rowv = NA, Colv = NA, scale = "none", col = my_palette)
```

---

## **Step 5: Add a Title and Labels**

You can add a main title and control margins:

```R
# Heatmap with titles and adjusted margins
heatmap(data_matrix, Rowv = NA, Colv = NA, scale = "none", 
        col = my_palette, 
        main = "My Customized Heatmap",
        margins = c(5, 10))  # (bottom, left)
```

---

## **Step 6: Control the Cell Annotations (Text Labels)**

`heatmap()` in base R doesn't natively allow text inside cells.
For that, you can use `image()` for a fully custom heatmap:

```R
# Use image() for full control
image(1:5, 1:5, data_matrix, col = my_palette, axes = FALSE, main = "Heatmap via image()")

# Add axis labels
axis(1, at = 1:5, labels = colnames(data_matrix))
axis(2, at = 1:5, labels = rev(rownames(data_matrix)))  # reverse row order

# Add text annotations
for (i in 1:5) {
  for (j in 1:5) {
    text(j, 6-i, round(data_matrix[i, j], 1))
  }
}
```

📝 **Note**: `image()` requires flipping row indices to match `heatmap()` orientation.

---

## **Step 7 (Optional): Save the Heatmap**

You can easily export the plot:

```R
# Save as PNG
png("heatmap.png", width=600, height=600)
heatmap(data_matrix, Rowv = NA, Colv = NA, scale = "none", col = my_palette, main = "Saved Heatmap")
dev.off()
```
