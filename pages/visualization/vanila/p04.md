
# 📊 **Tutorial - Progressive Histogram Tutorial in Base R**

We will use the built-in `mtcars` dataset for demonstration.

---

### **Step 1 — Load and Inspect Data**

```r
# Load built-in dataset
data(mtcars)

# Quick look at the data
head(mtcars)
```

Let's say we want to create a histogram of the variable `mpg` (Miles per gallon).

---

### **Step 2 — Basic Histogram**

```r
# Basic histogram
hist(mtcars$mpg)
```

➡ *This gives us the default histogram using base R defaults.*

---

### **Step 3 — Add Titles and Axis Labels**

```r
hist(mtcars$mpg,
     main = "Histogram of Miles Per Gallon",
     xlab = "Miles Per Gallon",
     ylab = "Frequency")
```

➡ *Now we have meaningful titles and axis labels.*

---

### **Step 4 — Customize Bins (Breaks)**

By default, R decides the number of bins, but you can control it using the `breaks` argument.

```r
hist(mtcars$mpg,
     breaks = 8,
     main = "Histogram with Custom Bins",
     xlab = "Miles Per Gallon",
     ylab = "Frequency")
```

➡ *This creates 8 bins (or classes). You can fine-tune this depending on your data distribution.*

---

### **Step 5 — Change Colors**

```r
hist(mtcars$mpg,
     breaks = 8,
     col = "skyblue",
     border = "black",
     main = "Colored Histogram",
     xlab = "Miles Per Gallon",
     ylab = "Frequency")
```

➡ *Color improves visualization and clarity.*

---

### **Step 6 — Add Density Line (Overlay Smooth Curve)**

Sometimes it's useful to overlay a density estimate.

```r
# Create histogram with probability density instead of frequency
hist(mtcars$mpg,
     breaks = 8,
     col = "lightgreen",
     border = "black",
     main = "Histogram with Density Curve",
     xlab = "Miles Per Gallon",
     ylab = "Density",
     prob = TRUE)

# Add density line
lines(density(mtcars$mpg), col = "red", lwd = 2)
```

➡ *Now we can see both the histogram and the smooth density curve together.*

---

### **Step 7 — Add Rug Plot**

A rug plot shows individual data points along the x-axis:

```r
hist(mtcars$mpg,
     breaks = 8,
     col = "lightyellow",
     border = "black",
     main = "Histogram with Rug Plot",
     xlab = "Miles Per Gallon",
     ylab = "Density",
     prob = TRUE)

lines(density(mtcars$mpg), col = "blue", lwd = 2)
rug(mtcars$mpg)
```

➡ *Rug plot adds more information about the actual data distribution.*

---

### **Step 8 — Horizontal Lines (Reference Lines)**

You can add reference lines for means or other statistics:

```r
hist(mtcars$mpg,
     breaks = 8,
     col = "lightpink",
     border = "black",
     main = "Histogram with Mean Line",
     xlab = "Miles Per Gallon",
     ylab = "Frequency")

abline(v = mean(mtcars$mpg), col = "red", lwd = 2, lty = 2)
```

➡ *This adds a vertical dashed line showing the mean value.*

---

# ✅ **Summary Table of Arguments**

| Argument       | Purpose                                       |
| -------------- | --------------------------------------------- |
| `breaks`       | Control number of bins                        |
| `col`          | Fill color                                    |
| `border`       | Border color                                  |
| `main`         | Main title                                    |
| `xlab`, `ylab` | Axis labels                                   |
| `prob=TRUE`    | Plot probability density instead of frequency |
| `lines()`      | Add density curve                             |
| `rug()`        | Add rug plot                                  |
| `abline()`     | Add reference line                            |
