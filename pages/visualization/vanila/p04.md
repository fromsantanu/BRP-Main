
# 📊 **Tutorial - Progressive Histogram Tutorial in Base R**

## **Step 1 — Load and Inspect Data**

```r
# Load built-in dataset
data(mtcars)

# Quick look at the data
head(mtcars)
```

🔍 **Explanation:**

* `data(mtcars)`
  Loads the **mtcars** dataset into your environment. This dataset contains data about fuel consumption and 10 aspects of automobile design for 32 cars.

* `head(mtcars)`
  Displays the **first 6 rows** of the dataset for quick inspection.

---

## **Step 2 — Basic Histogram**

```r
hist(mtcars$mpg)
```

🔍 **Explanation:**

* `hist()`
  Creates a **histogram** of the data provided.

* `mtcars$mpg`
  Refers to the **mpg (miles per gallon)** column from the mtcars dataset.

➡ This creates a **simple default histogram** showing frequency counts of mpg values.

---

## **Step 3 — Add Titles and Axis Labels**

```r
hist(mtcars$mpg,
     main = "Histogram of Miles Per Gallon",
     xlab = "Miles Per Gallon",
     ylab = "Frequency")
```

🔍 **Explanation of new parameters:**

* `main`
  Sets the **main title** of the plot.

* `xlab`
  Label for the **x-axis**.

* `ylab`
  Label for the **y-axis**.

➡ Adding these improves **clarity** and **interpretability** of the plot.

---

## **Step 4 — Customize Bins (Breaks)**

```r
hist(mtcars$mpg,
     breaks = 8,
     main = "Histogram with Custom Bins",
     xlab = "Miles Per Gallon",
     ylab = "Frequency")
```

🔍 **Explanation:**

* `breaks`
  Defines the **number of bins (classes)** in the histogram. More breaks show finer details; fewer breaks show broader distribution.

➡ In this example, it uses **8 bins** for the histogram.

---

## **Step 5 — Change Colors**

```r
hist(mtcars$mpg,
     breaks = 8,
     col = "skyblue",
     border = "black",
     main = "Colored Histogram",
     xlab = "Miles Per Gallon",
     ylab = "Frequency")
```

🔍 **Explanation of new parameters:**

* `col`
  Sets the **fill color** of the bars. Here, it is set to `"skyblue"`.

* `border`
  Sets the **border color** of the bars. Here, it is set to `"black"`.

➡ Adding color enhances **visual appeal** and makes plots easier to distinguish when printed or presented.

---

## **Step 6 — Add Density Line (Overlay Smooth Curve)**

```r
# Create histogram with probability density instead of frequency
hist(mtcars$mpg,
     breaks = 8,
     col = "lightgreen",
     border = "black",
     main = "Histogram with Density Curve",
     xlab = "Miles Per Gallon",
     ylab = "Density",
     prob = TRUE)

# Add density line
lines(density(mtcars$mpg), col = "red", lwd = 2)
```

🔍 **Explanation of new elements:**

* `prob = TRUE`
  When set to TRUE, the histogram shows **probability densities** instead of frequency counts. The area under the histogram sums to 1.

* `density()`
  Computes a **kernel density estimate**, creating a smooth curve approximating the data distribution.

* `lines()`
  Adds the **density curve** to the existing plot.

* `col = "red"` inside `lines()`
  Sets the color of the density line to **red**.

* `lwd = 2`
  Sets the **line width** to 2, making it thicker for better visibility.

➡ Combining histogram and density curve gives both **empirical frequencies** and **smooth distribution estimate** in one view.

---

## **Step 7 — Add Rug Plot**

```r
hist(mtcars$mpg,
     breaks = 8,
     col = "lightyellow",
     border = "black",
     main = "Histogram with Rug Plot",
     xlab = "Miles Per Gallon",
     ylab = "Density",
     prob = TRUE)

lines(density(mtcars$mpg), col = "blue", lwd = 2)
rug(mtcars$mpg)
```

🔍 **Explanation of new function:**

* `rug()`
  Adds **small tick marks** (rug plot) at the bottom of the histogram indicating **individual data points**.

➡ It shows the **exact locations** of data points, adding depth to the distribution view.

---

## **Step 8 — Add Reference Line (Mean Line)**

```r
hist(mtcars$mpg,
     breaks = 8,
     col = "lightpink",
     border = "black",
     main = "Histogram with Mean Line",
     xlab = "Miles Per Gallon",
     ylab = "Frequency")

abline(v = mean(mtcars$mpg), col = "red", lwd = 2, lty = 2)
```

🔍 **Explanation of new function:**

* `abline()`
  Adds a **line** to an existing plot. Here:

  * `v = mean(mtcars$mpg)` adds a **vertical line** at the mean value of mpg.
  * `col = "red"` sets the line color to **red**.
  * `lwd = 2` sets the **line width** to 2.
  * `lty = 2` sets the **line type** to dashed.

➡ This is useful to **highlight summary statistics** (mean or median) on plots.

---

# ✅ **Summary of Key Functions**

| Function / Parameter   | Purpose                             |
| ---------------------- | ----------------------------------- |
| `hist()`               | Create histogram                    |
| `breaks`               | Number of bins                      |
| `main`, `xlab`, `ylab` | Titles and labels                   |
| `col`                  | Fill color                          |
| `border`               | Border color                        |
| `prob=TRUE`            | Plot density instead of frequency   |
| `lines()`              | Add additional lines (e.g. density) |
| `density()`            | Compute density estimate            |
| `rug()`                | Add rug plot                        |
| `abline()`             | Add reference lines                 |

---

### 💡 **Tip:**

You can further refine histograms with:

* `xlim` and `ylim` to set axis limits.
* `labels = TRUE` inside `hist()` to show counts on bars.
* `freq = FALSE` is the old syntax equivalent to `prob = TRUE`.
