
# 🎯 **Tutorial - Progressive Heatmap creation in R (with `ggplot2`)**

We’ll use a small dummy dataset for illustration.

## **Step 1 — Load Libraries and Create Sample Data**

```r
# Load libraries
library(ggplot2)
library(dplyr)

# Create sample data
data <- expand.grid(
  Category1 = LETTERS[1:5],
  Category2 = letters[1:5]
)
set.seed(123)
data$Value <- runif(nrow(data), min=0, max=100)

head(data)
```

* We now have a dataframe with 2 categorical variables and one numeric variable.

---

## **Step 2 — Basic Heatmap**

```r
ggplot(data, aes(x = Category1, y = Category2, fill = Value)) +
  geom_tile()
```

✅ Now you get a basic heatmap.

---

## **Step 3 — Improve Color Scale**

Let’s add a color gradient to make it more visually meaningful.

```r
ggplot(data, aes(x = Category1, y = Category2, fill = Value)) +
  geom_tile() +
  scale_fill_gradient(low = "white", high = "steelblue")
```

✅ This adds a better visual contrast based on the value.

---

## **Step 4 — Add Titles and Labels**

Adding proper labels helps in interpretation.

```r
ggplot(data, aes(x = Category1, y = Category2, fill = Value)) +
  geom_tile() +
  scale_fill_gradient(low = "white", high = "steelblue") +
  labs(title = "Heatmap Example",
       x = "Category 1",
       y = "Category 2",
       fill = "Score")
```

✅ Now we have a title and axis labels.

---

## **Step 5 — Improve Theme**

Let’s make it visually cleaner using a minimal theme.

```r
ggplot(data, aes(x = Category1, y = Category2, fill = Value)) +
  geom_tile(color = "black") +  # add gridlines
  scale_fill_gradient(low = "white", high = "steelblue") +
  labs(title = "Heatmap Example",
       x = "Category 1",
       y = "Category 2",
       fill = "Score") +
  theme_minimal()
```

✅ We added black gridlines for tiles and applied a minimal theme.

---

## **Step 6 — Add Value Labels**

Sometimes it's helpful to show actual values inside each cell.

```r
ggplot(data, aes(x = Category1, y = Category2, fill = Value)) +
  geom_tile(color = "black") +
  geom_text(aes(label = sprintf("%.1f", Value)), size = 3) +
  scale_fill_gradient(low = "white", high = "steelblue") +
  labs(title = "Heatmap with Labels",
       x = "Category 1",
       y = "Category 2",
       fill = "Score") +
  theme_minimal()
```

✅ Now you have the numeric values displayed directly in each cell.

---

## **Step 7 — Use `viridis` Color Palette (better for perception)**

```r
library(viridis)

ggplot(data, aes(x = Category1, y = Category2, fill = Value)) +
  geom_tile(color = "black") +
  geom_text(aes(label = sprintf("%.1f", Value)), size = 3) +
  scale_fill_viridis(option = "C", direction = -1) +
  labs(title = "Heatmap with Viridis Color",
       x = "Category 1",
       y = "Category 2",
       fill = "Score") +
  theme_minimal()
```

✅ The `viridis` color scale is perceptually uniform and colorblind-friendly.

---

## **Optional: Rotate Axis Text for Better Readability**

```r
ggplot(data, aes(x = Category1, y = Category2, fill = Value)) +
  geom_tile(color = "black") +
  geom_text(aes(label = sprintf("%.1f", Value)), size = 3) +
  scale_fill_viridis(option = "C", direction = -1) +
  labs(title = "Final Refined Heatmap",
       x = "Category 1",
       y = "Category 2",
       fill = "Score") +
  theme_minimal() +
  theme(axis.text.x = element_text(angle = 45, hjust = 1))
```

✅ Now it looks polished and ready for presentation.
