
# 🎯 **Tutorial - Progressive Heatmap creation in R (with `ggplot2`)**

## **Step 1 — Load Libraries and Create Sample Data**

```r
# Load necessary libraries
library(ggplot2)   # for plotting
library(dplyr)     # for data manipulation
```

✅ **Explanation:**

* `library(ggplot2)` loads the ggplot2 package for creating plots.
* `library(dplyr)` loads dplyr for data wrangling (optional here).

---

### **Create sample data**

```r
# Create a sample dataframe with two categorical variables and one numeric value
data <- expand.grid(
  Category1 = LETTERS[1:5],   # Creates factor levels A to E
  Category2 = letters[1:5]    # Creates factor levels a to e
)

set.seed(123)  # For reproducibility of random numbers

data$Value <- runif(nrow(data), min=0, max=100)  # Generate random values between 0-100

head(data)
```

✅ **Explanation:**

* `expand.grid()` creates all combinations of Category1 and Category2.
* `set.seed()` ensures reproducibility of random numbers.
* `runif()` generates random numbers with **uniform distribution**.

---

## **Step 2 — Basic Heatmap**

```r
ggplot(data, aes(x = Category1, y = Category2, fill = Value)) +
  geom_tile()
```

✅ **Explanation:**

* `ggplot(data, aes(...))` initializes the plot with:

  * `x = Category1` (x-axis)
  * `y = Category2` (y-axis)
  * `fill = Value` (cell color based on Value)

* `geom_tile()` draws rectangles (tiles) for each x-y combination, filled by the specified variable.

---

## **Step 3 — Add Color Gradient**

```r
ggplot(data, aes(x = Category1, y = Category2, fill = Value)) +
  geom_tile() +
  scale_fill_gradient(low = "white", high = "steelblue")
```

✅ **Explanation:**

* `scale_fill_gradient()` sets a **continuous color gradient**, from **low (white)** to **high (steelblue)** values.

---

## **Step 4 — Add Titles and Axis Labels**

```r
ggplot(data, aes(x = Category1, y = Category2, fill = Value)) +
  geom_tile() +
  scale_fill_gradient(low = "white", high = "steelblue") +
  labs(title = "Heatmap Example",
       x = "Category 1",
       y = "Category 2",
       fill = "Score")
```

✅ **Explanation:**

* `labs()` adds plot labels:

  * `title`: Main title of the plot
  * `x`, `y`: Axis labels
  * `fill`: Legend title for the fill scale

---

## **Step 5 — Improve Theme and Add Tile Borders**

```r
ggplot(data, aes(x = Category1, y = Category2, fill = Value)) +
  geom_tile(color = "black") +   # Adds black border to each tile
  scale_fill_gradient(low = "white", high = "steelblue") +
  labs(title = "Heatmap Example",
       x = "Category 1",
       y = "Category 2",
       fill = "Score") +
  theme_minimal()
```

✅ **Explanation:**

* `geom_tile(color = "black")` adds **black borders** around each tile for clarity.
* `theme_minimal()` applies a clean minimalistic theme removing gridlines and background clutter.

---

## **Step 6 — Add Value Labels Inside Tiles**

```r
ggplot(data, aes(x = Category1, y = Category2, fill = Value)) +
  geom_tile(color = "black") +
  geom_text(aes(label = sprintf("%.1f", Value)), size = 3) +
  scale_fill_gradient(low = "white", high = "steelblue") +
  labs(title = "Heatmap with Labels",
       x = "Category 1",
       y = "Category 2",
       fill = "Score") +
  theme_minimal()
```

✅ **Explanation:**

* `geom_text()` adds text labels inside each tile.
* `aes(label = sprintf("%.1f", Value))` formats the Value to **1 decimal place**.
* `size = 3` sets the font size for text labels.

---

## **Step 7 — Use `viridis` Color Palette**

```r
library(viridis)

ggplot(data, aes(x = Category1, y = Category2, fill = Value)) +
  geom_tile(color = "black") +
  geom_text(aes(label = sprintf("%.1f", Value)), size = 3) +
  scale_fill_viridis(option = "C", direction = -1) +
  labs(title = "Heatmap with Viridis Color",
       x = "Category 1",
       y = "Category 2",
       fill = "Score") +
  theme_minimal()
```

✅ **Explanation:**

* `scale_fill_viridis()` from the **viridis package** uses perceptually uniform and colorblind-friendly colors.

  * `option = "C"` chooses one variant of the viridis palette.
  * `direction = -1` reverses the color scale if needed.

---

## **Step 8 — Rotate X-axis Text for Better Readability**

```r
ggplot(data, aes(x = Category1, y = Category2, fill = Value)) +
  geom_tile(color = "black") +
  geom_text(aes(label = sprintf("%.1f", Value)), size = 3) +
  scale_fill_viridis(option = "C", direction = -1) +
  labs(title = "Final Refined Heatmap",
       x = "Category 1",
       y = "Category 2",
       fill = "Score") +
  theme_minimal() +
  theme(axis.text.x = element_text(angle = 45, hjust = 1))
```

✅ **Explanation:**

* `theme(axis.text.x = element_text(angle = 45, hjust = 1))` rotates x-axis text by **45 degrees** with horizontal justification for readability.

---

# ✅ **Summary of Functions and Parameters**

| Function                | Purpose                                              |
| ----------------------- | ---------------------------------------------------- |
| `ggplot()`              | Initializes plot with data and aesthetics            |
| `aes()`                 | Defines mapping of data variables to plot aesthetics |
| `geom_tile()`           | Creates the heatmap tiles                            |
| `color = "black"`       | Adds border color to tiles                           |
| `scale_fill_gradient()` | Sets continuous color gradient                       |
| `scale_fill_viridis()`  | Uses viridis color palette                           |
| `labs()`                | Adds titles and axis labels                          |
| `geom_text()`           | Adds text labels inside tiles                        |
| `sprintf()`             | Formats numeric values as text labels                |
| `theme_minimal()`       | Applies minimalistic plot theme                      |
| `theme()`               | Further customize plot appearance (e.g. text angle)  |
