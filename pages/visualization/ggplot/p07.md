
# 🎯 **Tutorial - Progressive Heatmap creation in R (with `ggplot2`)**

## **Step 0: Load Libraries**

```r
library(ggplot2)   # For plotting
library(dplyr)     # For data manipulation
```

✅ **Explanation:**

* `ggplot2`: Main package for advanced visualizations.
* `dplyr`: Helps to manipulate data efficiently (e.g. mutate, arrange).

---

## **Step 1: Create Dataset**

```r
# Create sample data
data <- data.frame(
  category = c("A", "B", "C", "D"),
  count = c(10, 20, 30, 40)
)

# Preview data
print(data)
```

✅ **Explanation:**

* `data.frame()` creates a table with two columns: `category` (A-D) and their `count`.
* `print(data)` shows what the data looks like.

---

## **Step 2: Basic Pie Chart**

```r
ggplot(data, aes(x = "", y = count, fill = category)) +
  geom_bar(stat = "identity", width = 1) +
  coord_polar("y") +
  labs(title = "Basic Pie Chart")
```

✅ **Explanation of each function:**

| Function/Parameter                       | Meaning                                                                                                                                   |
| ---------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `ggplot(data, aes(...))`                 | Start plot with data and aesthetics (`x`, `y`, `fill`).                                                                                   |
| `x = ""`                                 | Creates a single stacked bar by setting x to an empty string.                                                                             |
| `y = count`                              | Height of bars is determined by `count`.                                                                                                  |
| `fill = category`                        | Different colors for each category.                                                                                                       |
| `geom_bar(stat = "identity", width = 1)` | Creates bar chart with actual count values (not counts of observations). `width=1` makes bars wide, ensuring they form a complete circle. |
| `coord_polar("y")`                       | Converts bar chart to pie chart using polar coordinates.                                                                                  |
| `labs(title = "...")`                    | Adds a title to the plot.                                                                                                                 |

---

## **Step 3: Calculate Percentages and Labels**

```r
data <- data %>%
  mutate(percentage = count / sum(count) * 100,       # Calculate %
         label = paste0(round(percentage, 1), "%"))   # Create label text
```

✅ **Explanation:**

* `mutate()` creates new columns.
* `percentage` is calculated as (count / total) \* 100.
* `round(percentage, 1)` rounds to 1 decimal place.
* `paste0(..., "%")` adds a % sign to each label.

---

## **Step 4: Pie Chart with Percentage Labels**

```r
ggplot(data, aes(x = "", y = count, fill = category)) +
  geom_bar(stat = "identity", width = 1) +
  coord_polar("y") +
  geom_text(aes(label = label),
            position = position_stack(vjust = 0.5)) +
  labs(title = "Pie Chart with Percentage Labels")
```

✅ **Explanation of new parts:**

| Function/Parameter                                                      | Meaning                                                                                                    |
| ----------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `geom_text(aes(label = label), position = position_stack(vjust = 0.5))` | Adds text labels at the middle of each slice. `vjust = 0.5` centers the text vertically within each slice. |

---

## **Step 5: Improve Aesthetics**

```r
ggplot(data, aes(x = "", y = count, fill = category)) +
  geom_bar(stat = "identity", width = 1, color = "white") +
  coord_polar("y") +
  geom_text(aes(label = label), position = position_stack(vjust = 0.5)) +
  scale_fill_brewer(palette = "Pastel1") +
  theme_void() +
  labs(title = "Refined Pie Chart")
```

✅ **Explanation of improvements:**

| Function/Parameter                       | Meaning                                                      |
| ---------------------------------------- | ------------------------------------------------------------ |
| `color = "white"`                        | Adds white borders between slices for clarity.               |
| `scale_fill_brewer(palette = "Pastel1")` | Uses a pleasant pastel color palette for better visuals.     |
| `theme_void()`                           | Removes axes, grid lines, and background for a cleaner plot. |

---

## **Step 6: Customize Legend Title & Theme**

```r
ggplot(data, aes(x = "", y = count, fill = category)) +
  geom_bar(stat = "identity", width = 1, color = "white") +
  coord_polar("y") +
  geom_text(aes(label = label), position = position_stack(vjust = 0.5)) +
  scale_fill_brewer(palette = "Set3", name = "Category") +
  theme_void() +
  theme(
    plot.title = element_text(hjust = 0.5, face = "bold", size = 16),
    legend.title = element_text(face = "bold")
  ) +
  labs(title = "Beautiful Pie Chart")
```

✅ **Explanation of new customizations:**

| Function/Parameter                                       | Meaning                                                                          |
| -------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `scale_fill_brewer(palette = "Set3", name = "Category")` | Sets palette to 'Set3' and names legend title as 'Category'.                     |
| `theme(plot.title = element_text(...))`                  | Centers the title (`hjust = 0.5`), makes it bold, and increases font size to 16. |
| `legend.title = element_text(face = "bold")`             | Makes legend title bold.                                                         |
