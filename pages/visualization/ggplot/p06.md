
# 📊 **Tutorial - Progressive Box Plot creation with `ggplot2`**


## **Step 1 — Load Library and Data**

```r
# Load ggplot2 library for creating plots
library(ggplot2)

# View first few rows of the built-in mtcars dataset
head(mtcars)
```

🔎 **Explanation:**

* `library(ggplot2)` — Loads the **ggplot2 package**, which is used for creating advanced plots in R.
* `head(mtcars)` — Shows the first six rows of the dataset to inspect variable names and structure.

---

## **Step 2 — Create a Basic Box Plot**

```r
ggplot(mtcars, aes(x = factor(cyl), y = mpg)) +
  geom_boxplot()
```

🔎 **Explanation:**

* `ggplot(mtcars, aes(...))` — Initializes the plot with the dataset `mtcars` and sets aesthetic mappings:

  * `x = factor(cyl)` — Treats **cyl** (number of cylinders) as a **categorical variable** by converting it into a factor.
  * `y = mpg` — Plots **mpg** (miles per gallon) as the dependent variable.

* `geom_boxplot()` — Adds the **box plot layer** to visualize the distribution of mpg for each cylinder group.

---

## **Step 3 — Add Title and Axis Labels**

```r
ggplot(mtcars, aes(x = factor(cyl), y = mpg)) +
  geom_boxplot() +
  labs(title = "MPG Distribution by Cylinder",
       x = "Number of Cylinders",
       y = "Miles Per Gallon")
```

🔎 **Explanation:**

* `labs(...)` — Adds labels:

  * `title` — Sets the main title.
  * `x` — Sets the x-axis label.
  * `y` — Sets the y-axis label.

---

## **Step 4 — Add Colors to Different Groups**

```r
ggplot(mtcars, aes(x = factor(cyl), y = mpg, fill = factor(cyl))) +
  geom_boxplot() +
  labs(title = "MPG Distribution by Cylinder",
       x = "Number of Cylinders",
       y = "Miles Per Gallon")
```

🔎 **Explanation:**

* `fill = factor(cyl)` inside `aes()` — Colors the boxes based on the **cyl** groups automatically using default colors.

---

## **Step 5 — Customize Colors Manually**

```r
ggplot(mtcars, aes(x = factor(cyl), y = mpg, fill = factor(cyl))) +
  geom_boxplot() +
  scale_fill_manual(values = c("skyblue", "orange", "lightgreen")) +
  labs(title = "MPG Distribution by Cylinder",
       x = "Number of Cylinders",
       y = "Miles Per Gallon")
```

🔎 **Explanation:**

* `scale_fill_manual(values = c(...))` — Manually sets custom fill colors for the different factor levels. The colors are assigned in order of factor levels.

---

## **Step 6 — Show Individual Data Points with Jitter**

```r
ggplot(mtcars, aes(x = factor(cyl), y = mpg, fill = factor(cyl))) +
  geom_boxplot(outlier.shape = NA) +  # Hides default outlier points in box plot
  geom_jitter(width = 0.2, size = 2, alpha = 0.7) +
  scale_fill_manual(values = c("skyblue", "orange", "lightgreen")) +
  labs(title = "MPG Distribution with Individual Data Points",
       x = "Number of Cylinders",
       y = "Miles Per Gallon")
```

🔎 **Explanation:**

* `outlier.shape = NA` in `geom_boxplot()` — Removes default outlier points so they do not overlap with jittered points.
* `geom_jitter(...)` — Adds individual data points with slight horizontal spread to avoid overlap:

  * `width = 0.2` — Controls horizontal spread (jittering).
  * `size = 2` — Sets point size.
  * `alpha = 0.7` — Sets transparency (0 fully transparent to 1 fully opaque).

---

## **Step 7 — Apply a Clean Theme**

```r
ggplot(mtcars, aes(x = factor(cyl), y = mpg, fill = factor(cyl))) +
  geom_boxplot(outlier.shape = NA) +
  geom_jitter(width = 0.2, size = 2, alpha = 0.7) +
  scale_fill_manual(values = c("skyblue", "orange", "lightgreen")) +
  labs(title = "MPG Distribution with Jittered Data Points",
       x = "Number of Cylinders",
       y = "Miles Per Gallon") +
  theme_minimal(base_size = 14)
```

🔎 **Explanation:**

* `theme_minimal(base_size = 14)` — Applies a minimalistic theme with base text size 14 for better readability.

---

## **Step 8 — Add Mean Points**

```r
ggplot(mtcars, aes(x = factor(cyl), y = mpg, fill = factor(cyl))) +
  geom_boxplot(outlier.shape = NA) +
  stat_summary(fun = mean, geom = "point", shape = 23, size = 3, fill = "red") +
  geom_jitter(width = 0.2, size = 2, alpha = 0.7) +
  scale_fill_manual(values = c("skyblue", "orange", "lightgreen")) +
  labs(title = "MPG Distribution with Mean and Data Points",
       x = "Number of Cylinders",
       y = "Miles Per Gallon") +
  theme_minimal(base_size = 14)
```

🔎 **Explanation:**

* `stat_summary(...)` — Adds summary statistics:

  * `fun = mean` — Calculates the mean for each group.
  * `geom = "point"` — Adds a point for the mean.
  * `shape = 23` — Uses a diamond shape.
  * `size = 3` — Sets the size of mean point.
  * `fill = "red"` — Colors the mean point red for visibility.
