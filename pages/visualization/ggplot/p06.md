
# 📊 **Tutorial - Progressive Box Plot creation with `ggplot2`**

We will use the built-in `mtcars` dataset for this tutorial.

---

## **Step 1 — Load Libraries and Data**

```r
# Load ggplot2
library(ggplot2)

# Use built-in mtcars dataset
data(mtcars)

# Quick look at data
head(mtcars)
```

---

## **Step 2 — Create a Basic Box Plot**

Let’s plot `mpg` (miles per gallon) grouped by the number of cylinders (`cyl`).

```r
ggplot(mtcars, aes(x = factor(cyl), y = mpg)) +
  geom_boxplot()
```

* `x = factor(cyl)` — we treat `cyl` as a categorical variable.
* `y = mpg` — dependent variable.
* `geom_boxplot()` — adds the box plot layer.

---

## **Step 3 — Add Title and Axis Labels**

Let’s improve the plot with title and axis labels:

```r
ggplot(mtcars, aes(x = factor(cyl), y = mpg)) +
  geom_boxplot() +
  labs(title = "MPG Distribution by Cylinder",
       x = "Number of Cylinders",
       y = "Miles Per Gallon")
```

---

## **Step 4 — Add Colors**

You can color by group (fill):

```r
ggplot(mtcars, aes(x = factor(cyl), y = mpg, fill = factor(cyl))) +
  geom_boxplot() +
  labs(title = "MPG Distribution by Cylinder",
       x = "Number of Cylinders",
       y = "Miles Per Gallon")
```

---

## **Step 5 — Customize Colors Manually**

```r
ggplot(mtcars, aes(x = factor(cyl), y = mpg, fill = factor(cyl))) +
  geom_boxplot() +
  scale_fill_manual(values = c("skyblue", "orange", "lightgreen")) +
  labs(title = "MPG Distribution by Cylinder",
       x = "Number of Cylinders",
       y = "Miles Per Gallon")
```

---

## **Step 6 — Show Data Points (Overlay Jitter)**

We can add individual data points using `geom_jitter()`:

```r
ggplot(mtcars, aes(x = factor(cyl), y = mpg, fill = factor(cyl))) +
  geom_boxplot(outlier.shape = NA) +  # Hide default outliers
  geom_jitter(width = 0.2, size = 2, alpha = 0.7) +
  scale_fill_manual(values = c("skyblue", "orange", "lightgreen")) +
  labs(title = "MPG Distribution with Individual Data Points",
       x = "Number of Cylinders",
       y = "Miles Per Gallon")
```

---

## **Step 7 — Theme Refinements**

Add a cleaner theme:

```r
ggplot(mtcars, aes(x = factor(cyl), y = mpg, fill = factor(cyl))) +
  geom_boxplot(outlier.shape = NA) +
  geom_jitter(width = 0.2, size = 2, alpha = 0.7) +
  scale_fill_manual(values = c("skyblue", "orange", "lightgreen")) +
  labs(title = "MPG Distribution with Jittered Data Points",
       x = "Number of Cylinders",
       y = "Miles Per Gallon") +
  theme_minimal(base_size = 14)
```

---

## **Step 8 — Final Touch: Add Mean Points**

Sometimes it's nice to add mean indicators:

```r
ggplot(mtcars, aes(x = factor(cyl), y = mpg, fill = factor(cyl))) +
  geom_boxplot(outlier.shape = NA) +
  stat_summary(fun = mean, geom = "point", shape = 23, size = 3, fill = "red") +
  geom_jitter(width = 0.2, size = 2, alpha = 0.7) +
  scale_fill_manual(values = c("skyblue", "orange", "lightgreen")) +
  labs(title = "MPG Distribution with Mean and Data Points",
       x = "Number of Cylinders",
       y = "Miles Per Gallon") +
  theme_minimal(base_size = 14)
```
