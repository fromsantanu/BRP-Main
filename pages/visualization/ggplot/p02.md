
# 📊 **Tutorial - Progressive Bar Chart Creation in R (with ggplot2)**

## **Step 1: Load Required Packages**

```r
install.packages("ggplot2")  # Installs ggplot2 if not installed
library(ggplot2)             # Loads ggplot2 into current R session
```

✔️ **Explanation:**

* `install.packages()` installs the package (run once).
* `library()` loads the package so you can use its functions.

---

## **Step 2: Create a Sample Dataset**

```r
data <- data.frame(
  Region = c("North", "South", "East", "West"),
  Sales = c(150, 200, 180, 130)
)

print(data)
```

✔️ **Explanation:**

* `data.frame()` creates a table-like structure with columns `Region` and `Sales`.
* `print(data)` displays it for verification.

---

## **Step 3: Basic Bar Chart**

```r
ggplot(data, aes(x = Region, y = Sales)) +
  geom_bar(stat = "identity")
```

✔️ **Explanation:**

* `ggplot(data, aes(...))` initializes the plot with dataset `data` and sets **aesthetic mappings (aes)**:

  * `x = Region`: categorical variable for x-axis.
  * `y = Sales`: numeric variable for bar heights.
* `geom_bar(stat = "identity")`:

  * `geom_bar()` adds bar geometry.
  * `stat = "identity"` tells ggplot to use the actual `Sales` values as bar heights (otherwise it counts rows).

---

## **Step 4: Add Labels and Titles**

```r
ggplot(data, aes(x = Region, y = Sales)) +
  geom_bar(stat = "identity") +
  labs(title = "Sales by Region", x = "Region", y = "Sales (in units)")
```

✔️ **Explanation:**

* `labs()` adds:

  * `title`: Main title of the plot.
  * `x`: Label for x-axis.
  * `y`: Label for y-axis.

---

## **Step 5: Add Colors**

```r
ggplot(data, aes(x = Region, y = Sales, fill = Region)) +
  geom_bar(stat = "identity") +
  labs(title = "Sales by Region", x = "Region", y = "Sales (in units)") +
  theme_minimal()
```

✔️ **Explanation:**

* `fill = Region` inside `aes()` assigns different colors to bars based on `Region`.
* `theme_minimal()` applies a minimal clean theme to the plot for better visual aesthetics.

---

## **Step 6: Change Bar Colors Manually**

```r
ggplot(data, aes(x = Region, y = Sales, fill = Region)) +
  geom_bar(stat = "identity") +
  scale_fill_manual(values = c("North" = "#FF9999", "South" = "#66B2FF", "East" = "#99FF99", "West" = "#FFCC99")) +
  labs(title = "Sales by Region", x = "Region", y = "Sales (in units)") +
  theme_minimal()
```

✔️ **Explanation:**

* `scale_fill_manual()` manually sets custom colors for each region using hex codes.

---

## **Step 7: Add Data Labels on Bars**

```r
ggplot(data, aes(x = Region, y = Sales, fill = Region)) +
  geom_bar(stat = "identity") +
  geom_text(aes(label = Sales), vjust = -0.5, size = 5) +
  scale_fill_manual(values = c("North" = "#FF9999", "South" = "#66B2FF", "East" = "#99FF99", "West" = "#FFCC99")) +
  labs(title = "Sales by Region", x = "Region", y = "Sales (in units)") +
  theme_minimal()
```

✔️ **Explanation:**

* `geom_text()` adds text labels on bars.

  * `aes(label = Sales)`: displays sales value as label.
  * `vjust = -0.5`: vertical adjustment to place labels above bars.
  * `size = 5`: controls text size.

---

## **Step 8: Improve Theme and Font Sizes**

```r
ggplot(data, aes(x = Region, y = Sales, fill = Region)) +
  geom_bar(stat = "identity", width = 0.6) +
  geom_text(aes(label = Sales), vjust = -0.5, size = 5, color = "black") +
  scale_fill_manual(values = c("North" = "#FF9999", "South" = "#66B2FF", "East" = "#99FF99", "West" = "#FFCC99")) +
  labs(title = "Sales by Region", subtitle = "Q1 2025", x = "Region", y = "Sales (in units)") +
  theme_minimal(base_size = 14) +
  theme(legend.position = "none")
```

✔️ **Explanation:**

* `width = 0.6` in `geom_bar()`: makes bars narrower for aesthetics.
* `color = "black"` in `geom_text()`: sets text color.
* `subtitle = "Q1 2025"` in `labs()`: adds a subtitle.
* `theme_minimal(base_size = 14)`: sets base font size to 14 for better readability.
* `theme(legend.position = "none")`: removes the legend since bar colors already indicate regions.

---

# ✅ **Summary**

* **ggplot(data, aes(...))**: Initialize plot and aesthetics.
* **geom\_bar(stat = "identity")**: Draw bars with actual heights.
* **geom\_text()**: Add text labels on bars.
* **scale\_fill\_manual()**: Customize bar colors.
* **labs()**: Add titles and axis labels.
* **theme\_minimal() / theme()**: Change plot theme and appearance.
