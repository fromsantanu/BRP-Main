# 📊 **Tutorial - Progressive Scatter Plot Creation in R and ggplot2**


We will use the **ggplot2 package**, which is part of the tidyverse and widely used for elegant data visualisation.

---

## **Step 0. Setup**

```R
# Install ggplot2 if not installed
install.packages("ggplot2")

# Load ggplot2 library
library(ggplot2)
```

🔍 **Explanation:**

* `install.packages("ggplot2")` installs the package from CRAN.
* `library(ggplot2)` loads it into your current R session to use its functions.

---

## **Step 1. Prepare Data**

```R
# Create sample data
set.seed(123) # for reproducibility

data <- data.frame(
  Height = rnorm(100, mean = 170, sd = 10),  # random heights
  Weight = rnorm(100, mean = 70, sd = 15)    # random weights
)

head(data)  # View first few rows
```

🔍 **Explanation:**

* `set.seed(123)` ensures the same random data is generated each time (useful for reproducibility).
* `rnorm(n, mean, sd)` generates `n` random numbers from a normal distribution.
* `data.frame()` creates a data frame with two columns: `Height` and `Weight`.
* `head(data)` displays the first six rows to inspect the dataset.

---

## **Step 2. Basic Scatter Plot**

```R
ggplot(data, aes(x = Height, y = Weight)) +
  geom_point()
```

🔍 **Explanation:**

* `ggplot(data, aes(x = Height, y = Weight))` initializes a ggplot object with data and aesthetic mappings (x and y variables).
* `geom_point()` adds the scatter plot layer (points).

---

## **Step 3. Add Titles and Axis Labels**

```R
ggplot(data, aes(x = Height, y = Weight)) +
  geom_point() +
  labs(
    title = "Height vs Weight Scatter Plot",
    x = "Height (cm)",
    y = "Weight (kg)"
  )
```

🔍 **Explanation:**

* `labs()` adds labels:

  * `title` sets the main title.
  * `x` and `y` set axis labels.

---

## **Step 4. Improve Point Appearance**

```R
ggplot(data, aes(x = Height, y = Weight)) +
  geom_point(color = "blue", size = 2, shape = 19) +
  labs(
    title = "Height vs Weight Scatter Plot",
    x = "Height (cm)",
    y = "Weight (kg)"
  )
```

🔍 **Explanation of `geom_point()` arguments:**

* `color = "blue"` sets point colour.
* `size = 2` sets point size.
* `shape = 19` specifies filled circle.

---

## **Step 5. Add Regression Line**

```R
ggplot(data, aes(x = Height, y = Weight)) +
  geom_point(color = "blue", size = 2, shape = 19) +
  geom_smooth(method = "lm", se = TRUE, color = "red") +
  labs(
    title = "Height vs Weight with Regression Line",
    x = "Height (cm)",
    y = "Weight (kg)"
  )
```

🔍 **Explanation of `geom_smooth()`:**

* Adds a trend line (default is LOESS, but here we use `method = "lm"` for linear model).
* `se = TRUE` adds confidence interval shading.
* `color = "red"` sets line colour.

---

## **Step 6. Enhance Theme and Style**

```R
ggplot(data, aes(x = Height, y = Weight)) +
  geom_point(color = "blue", size = 2, shape = 19, alpha = 0.6) +
  geom_smooth(method = "lm", se = TRUE, color = "red", linetype = "dashed") +
  labs(
    title = "Height vs Weight with Regression Line",
    subtitle = "Sample data (N = 100)",
    x = "Height (cm)",
    y = "Weight (kg)",
    caption = "Data simulated for demo"
  ) +
  theme_minimal()
```

🔍 **Explanation of additional arguments:**

* `alpha = 0.6` makes points semi-transparent (good for overlapping points).
* `linetype = "dashed"` makes the regression line dashed.
* `subtitle` adds a smaller subtitle below the title.
* `caption` adds text at bottom right.
* `theme_minimal()` applies a clean minimal theme.

---

## **Step 7. Grouped Scatter Plot (Advanced)**

Add a grouping variable for colour differentiation.

```R
# Add Gender column
data$Gender <- sample(c("Male", "Female"), size = 100, replace = TRUE)

ggplot(data, aes(x = Height, y = Weight, color = Gender)) +
  geom_point(size = 2, alpha = 0.6) +
  geom_smooth(method = "lm", se = FALSE) +
  labs(
    title = "Height vs Weight by Gender",
    x = "Height (cm)",
    y = "Weight (kg)"
  ) +
  theme_classic()
```

🔍 **Explanation:**

* `color = Gender` maps colour to Gender variable for subgroup visualisation.
* `sample()` creates random gender assignment here for demonstration.
* `theme_classic()` applies a clean classic theme.

---

## **Step 8. Save the Plot**

```R
# Save to PNG file
ggsave("scatter_plot.png", width = 7, height = 5, dpi = 300)
```

🔍 **Explanation:**

* `ggsave()` saves the last plot to a file.
* `width`, `height` in inches; `dpi = 300` ensures high resolution.

---

# ✅ **Key Functions Summary**

| Function        | Purpose                                           |
| --------------- | ------------------------------------------------- |
| `ggplot()`      | Initializes plot with data and aesthetic mappings |
| `aes()`         | Defines variable mappings (x, y, colour, etc.)    |
| `geom_point()`  | Adds scatter plot points                          |
| `geom_smooth()` | Adds smoothed trend line or regression line       |
| `labs()`        | Adds title, subtitles, captions, and axis labels  |
| `theme_*()`     | Applies styling themes                            |
| `ggsave()`      | Saves the plot as a file                          |
