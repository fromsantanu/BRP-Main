# 📊 **Tutorial - Progressive Scatter Plot Creation in R and ggplot2**

## **Step 0: Setup**

```R
# Install and load ggplot2 if not already installed
install.packages("ggplot2")
library(ggplot2)
```

For demonstration, we’ll use a simple dataset:

```R
# Sample dataset
set.seed(123)
data <- data.frame(
  Height = rnorm(100, mean = 170, sd = 10),
  Weight = rnorm(100, mean = 70, sd = 15)
)
head(data)
```

---

## **Step 1: Basic Scatter Plot**

```R
# Basic scatter plot
ggplot(data, aes(x = Height, y = Weight)) +
  geom_point()
```

✅ We have a basic scatter plot.

---

## **Step 2: Add Titles and Axis Labels**

```R
ggplot(data, aes(x = Height, y = Weight)) +
  geom_point() +
  labs(
    title = "Height vs Weight Scatter Plot",
    x = "Height (cm)",
    y = "Weight (kg)"
  )
```

✅ More informative now.

---

## **Step 3: Improve Point Appearance (color, size, shape)**

```R
ggplot(data, aes(x = Height, y = Weight)) +
  geom_point(color = "blue", size = 2, shape = 19) +
  labs(
    title = "Height vs Weight Scatter Plot",
    x = "Height (cm)",
    y = "Weight (kg)"
  )
```

✅ Points are easier to see.

---

## **Step 4: Add Trend Line (Regression Line)**

```R
ggplot(data, aes(x = Height, y = Weight)) +
  geom_point(color = "blue", size = 2, shape = 19) +
  geom_smooth(method = "lm", se = TRUE, color = "red") +
  labs(
    title = "Height vs Weight with Regression Line",
    x = "Height (cm)",
    y = "Weight (kg)"
  )
```

✅ Now we see the relationship trend.

---

## **Step 5: Enhance Theme and Style**

```R
ggplot(data, aes(x = Height, y = Weight)) +
  geom_point(color = "blue", size = 2, shape = 19, alpha = 0.6) +
  geom_smooth(method = "lm", se = TRUE, color = "red", linetype = "dashed") +
  labs(
    title = "Height vs Weight with Regression Line",
    subtitle = "Sample data (N = 100)",
    x = "Height (cm)",
    y = "Weight (kg)",
    caption = "Data simulated for demo"
  ) +
  theme_minimal()
```

✅ Cleaner and more professional look.

---

## **Step 6: Handle Grouped Data (Optional Advanced)**

Let’s say we have gender groups:

```R
data$Gender <- sample(c("Male", "Female"), size = 100, replace = TRUE)

ggplot(data, aes(x = Height, y = Weight, color = Gender)) +
  geom_point(size = 2, alpha = 0.6) +
  geom_smooth(method = "lm", se = FALSE) +
  labs(
    title = "Height vs Weight by Gender",
    x = "Height (cm)",
    y = "Weight (kg)"
  ) +
  theme_classic()
```

✅ Now we can compare subgroups.

---

## **Step 7: Save the Plot**

```R
# Save plot to file
ggsave("scatter_plot.png", width = 7, height = 5, dpi = 300)
```
