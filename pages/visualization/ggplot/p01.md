
# 📊 **Tutorial - Progressive Creation of a Line Plot in R with ggplot2**

---
Here is the **progressive tutorial with explanations for each function and instruction** used in building a **Line Plot using ggplot2 in R**:
---
## 🔧 **Step 1: Setup and Sample Data**

```R
# Load library
library(ggplot2)
```

✅ **Explanation**:

* `library(ggplot2)` loads the `ggplot2` package, which is a powerful plotting library in R based on the grammar of graphics.

---

```R
# Create sample data
data <- data.frame(
  Month = 1:12,
  Sales = c(120, 135, 150, 160, 145, 170, 180, 175, 160, 155, 140, 130)
)
```

✅ **Explanation**:

* `data.frame()` creates a table-like data structure.
* `Month = 1:12` creates a sequence from 1 to 12 representing months.
* `Sales = c(...)` is a vector of sales data for each month.

---

```R
# Quick look at data
print(data)
```

✅ **Explanation**:

* `print(data)` displays the created data frame to check its structure.

---

## 🔧 **Step 2: Basic Line Plot**

```R
ggplot(data, aes(x = Month, y = Sales)) +
  geom_line()
```

✅ **Explanation**:

* `ggplot(data, aes(x = Month, y = Sales))` initializes a ggplot object using **data** and sets aesthetics `x` as Month and `y` as Sales.
* `geom_line()` adds a **line geometry** to connect data points sequentially.

---

## 🔧 **Step 3: Add Points**

```R
ggplot(data, aes(x = Month, y = Sales)) +
  geom_line() +
  geom_point()
```

✅ **Explanation**:

* `geom_point()` overlays **points** at each data observation on the existing line plot for clarity.

---

## 🔧 **Step 4: Add Titles and Axis Labels**

```R
ggplot(data, aes(x = Month, y = Sales)) +
  geom_line() +
  geom_point() +
  labs(title = "Monthly Sales Over a Year",
       x = "Month",
       y = "Sales (in units)")
```

✅ **Explanation**:

* `labs()` adds plot **labels**:

  * `title` – main title of the plot.
  * `x` – label for x-axis.
  * `y` – label for y-axis.

---

## 🔧 **Step 5: Customize Line Color, Point Shape, and Size**

```R
ggplot(data, aes(x = Month, y = Sales)) +
  geom_line(color = "blue", size = 1.2) +
  geom_point(color = "red", size = 3, shape = 16) +
  labs(title = "Monthly Sales Over a Year",
       x = "Month",
       y = "Sales (in units)")
```

✅ **Explanation**:

* `color = "blue"` sets line color to blue.
* `size = 1.2` makes the line thicker.
* In `geom_point()`:

  * `color = "red"` sets point color.
  * `size = 3` increases point size.
  * `shape = 16` uses a solid circle (16 is ggplot’s code for filled circle).

---

## 🔧 **Step 6: Customize X-axis with Month Names**

```R
# Create month names
data$MonthName <- month.abb[data$Month]
```

✅ **Explanation**:

* `month.abb` is a built-in vector of abbreviated month names (Jan, Feb, etc).
* `data$MonthName <- month.abb[data$Month]` creates a new column with corresponding month names for the numeric months.

---

```R
ggplot(data, aes(x = MonthName, y = Sales, group = 1)) +
  geom_line(color = "blue", size = 1.2) +
  geom_point(color = "red", size = 3, shape = 16) +
  labs(title = "Monthly Sales Over a Year",
       x = "Month",
       y = "Sales (in units)")
```

✅ **Explanation**:

* `x = MonthName` uses the newly created month names for x-axis.
* `group = 1` tells ggplot to treat data as one group to connect them with a line when using a categorical x-axis.

---

## 🔧 **Step 7: Add Theme for Better Visuals**

```R
ggplot(data, aes(x = MonthName, y = Sales, group = 1)) +
  geom_line(color = "blue", size = 1.2) +
  geom_point(color = "red", size = 3, shape = 16) +
  labs(title = "Monthly Sales Over a Year",
       x = "Month",
       y = "Sales (in units)") +
  theme_minimal()
```

✅ **Explanation**:

* `theme_minimal()` changes the plot theme to a clean, minimalistic background, improving readability.

---

## 🔧 **Step 8: Add Data Labels**

```R
ggplot(data, aes(x = MonthName, y = Sales, group = 1)) +
  geom_line(color = "blue", size = 1.2) +
  geom_point(color = "red", size = 3, shape = 16) +
  geom_text(aes(label = Sales), vjust = -1, size = 3.5) +
  labs(title = "Monthly Sales Over a Year",
       x = "Month",
       y = "Sales (in units)") +
  theme_minimal()
```

✅ **Explanation**:

* `geom_text(aes(label = Sales), vjust = -1, size = 3.5)` adds text labels showing sales values:

  * `label = Sales` shows the sales number at each point.
  * `vjust = -1` positions the label slightly above the point.
  * `size = 3.5` sets text size.

---

## 🔧 **Step 9: Smooth Line (Optional Trend)**

```R
ggplot(data, aes(x = Month, y = Sales)) +
  geom_point(color = "red", size = 3) +
  geom_smooth(method = "loess", se = FALSE, color = "blue", size = 1.2) +
  labs(title = "Smoothed Monthly Sales Trend",
       x = "Month",
       y = "Sales (in units)") +
  theme_minimal()
```

✅ **Explanation**:

* `geom_smooth()` adds a smoothed trend line:

  * `method = "loess"` uses local polynomial regression fitting.
  * `se = FALSE` removes confidence interval shading around the smooth line.
  * `color` and `size` customize its appearance.

---

# 📝 **Summary Table: Commands & Explanations**

| **Function / Command**   | **Purpose**                                             |
| ------------------------ | ------------------------------------------------------- |
| `library(ggplot2)`       | Load ggplot2 package                                    |
| `data.frame()`           | Create a data table                                     |
| `ggplot()`               | Initialize plot with data and aesthetics                |
| `aes()`                  | Define aesthetic mappings (x, y, color, etc)            |
| `geom_line()`            | Draw line connecting data points                        |
| `geom_point()`           | Plot points on data                                     |
| `labs()`                 | Add titles and axis labels                              |
| `color`, `size`, `shape` | Customize aesthetics of geoms                           |
| `month.abb`              | Built-in month abbreviations                            |
| `group = 1`              | Treat data as one group for lines on categorical x-axis |
| `theme_minimal()`        | Minimalist plot theme                                   |
| `geom_text()`            | Add text labels                                         |
| `geom_smooth()`          | Add smoothed trend line                                 |
