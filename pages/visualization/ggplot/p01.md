
# 📊 **Tutorial - Progressive Creation of a Line Plot in R with ggplot2**

---

## 🔧 **Step 1: Setup and Sample Data**

First, let's load required libraries and create some sample data.

```R
# Load library
library(ggplot2)

# Create sample data
data <- data.frame(
  Month = 1:12,
  Sales = c(120, 135, 150, 160, 145, 170, 180, 175, 160, 155, 140, 130)
)

# Quick look at data
print(data)
```

---

## 🔧 **Step 2: Basic Line Plot**

Let’s create the most basic line plot.

```R
# Basic Line Plot
ggplot(data, aes(x = Month, y = Sales)) +
  geom_line()
```

This gives you a simple line plot. But it’s very basic — no labels, no colors, no titles.

---

## 🔧 **Step 3: Add Points**

Adding data points helps emphasize where each observation lies.

```R
ggplot(data, aes(x = Month, y = Sales)) +
  geom_line() +
  geom_point()
```

---

## 🔧 **Step 4: Improve Labels and Titles**

Always make your plot informative.

```R
ggplot(data, aes(x = Month, y = Sales)) +
  geom_line() +
  geom_point() +
  labs(title = "Monthly Sales Over a Year",
       x = "Month",
       y = "Sales (in units)")
```

---

## 🔧 **Step 5: Customize Line Color, Point Shape, and Size**

Aesthetic improvements make plots easier to read.

```R
ggplot(data, aes(x = Month, y = Sales)) +
  geom_line(color = "blue", size = 1.2) +
  geom_point(color = "red", size = 3, shape = 16) +
  labs(title = "Monthly Sales Over a Year",
       x = "Month",
       y = "Sales (in units)")
```

---

## 🔧 **Step 6: Customize Axes (e.g., Month Names)**

You can replace numbers with month names for better readability.

```R
# Create month names
data$MonthName <- month.abb[data$Month]

ggplot(data, aes(x = MonthName, y = Sales, group = 1)) +
  geom_line(color = "blue", size = 1.2) +
  geom_point(color = "red", size = 3, shape = 16) +
  labs(title = "Monthly Sales Over a Year",
       x = "Month",
       y = "Sales (in units)")
```

Note: We added `group = 1` so that ggplot knows it's one continuous series.

---

## 🔧 **Step 7: Add Theme for Better Presentation**

Use `theme_minimal()`, `theme_bw()`, or others to make it visually pleasing.

```R
ggplot(data, aes(x = MonthName, y = Sales, group = 1)) +
  geom_line(color = "blue", size = 1.2) +
  geom_point(color = "red", size = 3, shape = 16) +
  labs(title = "Monthly Sales Over a Year",
       x = "Month",
       y = "Sales (in units)") +
  theme_minimal()
```

---

## 🔧 **Step 8: Add Data Labels**

You may want to show exact values at each point.

```R
ggplot(data, aes(x = MonthName, y = Sales, group = 1)) +
  geom_line(color = "blue", size = 1.2) +
  geom_point(color = "red", size = 3, shape = 16) +
  geom_text(aes(label = Sales), vjust = -1, size = 3.5) +
  labs(title = "Monthly Sales Over a Year",
       x = "Month",
       y = "Sales (in units)") +
  theme_minimal()
```

---

## 🔧 **Step 9: Smooth Line (Optional Refinement)**

Sometimes, a smoothed version helps show trend.

```R
ggplot(data, aes(x = Month, y = Sales)) +
  geom_point(color = "red", size = 3) +
  geom_smooth(method = "loess", se = FALSE, color = "blue", size = 1.2) +
  labs(title = "Smoothed Monthly Sales Trend",
       x = "Month",
       y = "Sales (in units)") +
  theme_minimal()
```
