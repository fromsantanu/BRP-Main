
# 🥧 **Tutorial - Progressive Pie Chart creation in R using ggplot2**

> **Note:** ggplot2 doesn't have a native pie chart function. We create pie charts using bar plots with `coord_polar()`.

We will start simple and progressively refine the pie chart.

---

### **Step 1: Basic Dataset**

Let’s create a simple dataset:

```r
# Load required libraries
library(ggplot2)
library(dplyr)

# Create sample data
data <- data.frame(
  category = c("A", "B", "C", "D"),
  count = c(10, 20, 30, 40)
)

# Preview
print(data)
```

---

### **Step 2: Basic Pie Chart**

We start by using a bar chart and converting it to polar coordinates:

```r
ggplot(data, aes(x = "", y = count, fill = category)) +
  geom_bar(stat = "identity", width = 1) +
  coord_polar("y") +
  labs(title = "Basic Pie Chart")
```

* `x = ""` creates a single bar stacked.
* `coord_polar("y")` turns it into a pie.

---

### **Step 3: Add Percentage Labels**

First, calculate percentages:

```r
data <- data %>%
  mutate(percentage = count / sum(count) * 100,
         label = paste0(round(percentage, 1), "%"))

print(data)
```

Now, add labels:

```r
ggplot(data, aes(x = "", y = count, fill = category)) +
  geom_bar(stat = "identity", width = 1) +
  coord_polar("y") +
  geom_text(aes(label = label),
            position = position_stack(vjust = 0.5)) +
  labs(title = "Pie Chart with Percentage Labels")
```

---

### **Step 4: Improve Aesthetics**

* Remove axis
* Apply nicer colors

```r
ggplot(data, aes(x = "", y = count, fill = category)) +
  geom_bar(stat = "identity", width = 1, color = "white") +
  coord_polar("y") +
  geom_text(aes(label = label), position = position_stack(vjust = 0.5)) +
  scale_fill_brewer(palette = "Pastel1") +
  theme_void() +  # Removes background, axes, grid
  labs(title = "Refined Pie Chart")
```

---

### **Step 5: Add Legend Title & Customize Theme**

```r
ggplot(data, aes(x = "", y = count, fill = category)) +
  geom_bar(stat = "identity", width = 1, color = "white") +
  coord_polar("y") +
  geom_text(aes(label = label), position = position_stack(vjust = 0.5)) +
  scale_fill_brewer(palette = "Set3", name = "Category") +
  theme_void() +
  theme(
    plot.title = element_text(hjust = 0.5, face = "bold", size = 16),
    legend.title = element_text(face = "bold")
  ) +
  labs(title = "Beautiful Pie Chart")
```

### **Optional - A Donut Chart with exploded portion**

### ✅ Let's clarify:

#### In `ggplot2`, if you want a real "exploded" pie chart (i.e., slices pulled apart), we need to **manually simulate** this separation.

We can do this by:

1️⃣ **Creating offsets** for the slices (i.e., pushing certain slices outward).

2️⃣ **Using polar coordinates with adjusted positions.**

---

### 👉 Here’s a more correct simulated "exploded" pie chart example:

```r
library(ggplot2)
library(dplyr)

# Sample data
data <- data.frame(
  category = c("A", "B", "C", "D"),
  count = c(10, 20, 30, 40)
)

# Calculate cumulative positions
data <- data %>%
  arrange(desc(category)) %>%
  mutate(
    fraction = count / sum(count),
    ymax = cumsum(fraction),
    ymin = c(0, head(ymax, n=-1)),
    labelPosition = (ymax + ymin) / 2,
    label = paste0(category, "\n", round(fraction*100), "%")
  )

# Create an 'offset' for explosion
data$offset <- ifelse(data$category == "B", 0.05, 0)  # Only explode category B

# Plot
ggplot(data, aes(ymax=ymax, ymin=ymin, xmax=1 + offset, xmin=offset, fill=category)) +
  geom_rect() +
  coord_polar(theta="y") +
  xlim(c(-0.5, 1.5)) +  # adjust limits to leave space
  theme_void() +
  geom_text(aes(x = 1 + offset/2, y = labelPosition, label = label), size=4) +
  scale_fill_brewer(palette = "Set3") +
  labs(title = "Simulated Exploded Pie Chart")
```

---

### 🔎 **Explanation:**

* We build the pie chart manually with `geom_rect()` and `coord_polar()`.
* `offset` column allows you to pull specific slices outward.
* Adjust `offset` values for each slice as desired.
