
# 🥧 **Tutorial - Progressive Pie Chart creation in R using ggplot2**

> **Note:** ggplot2 doesn't have a native pie chart function. We create pie charts using bar plots with `coord_polar()`.

We will start simple and progressively refine the pie chart.

---

### **Step 1: Basic Dataset**

Let’s create a simple dataset:

```r
# Load required libraries
library(ggplot2)
library(dplyr)

# Create sample data
data <- data.frame(
  category = c("A", "B", "C", "D"),
  count = c(10, 20, 30, 40)
)

# Preview
print(data)
```

---

### **Step 2: Basic Pie Chart**

We start by using a bar chart and converting it to polar coordinates:

```r
ggplot(data, aes(x = "", y = count, fill = category)) +
  geom_bar(stat = "identity", width = 1) +
  coord_polar("y") +
  labs(title = "Basic Pie Chart")
```

* `x = ""` creates a single bar stacked.
* `coord_polar("y")` turns it into a pie.

---

### **Step 3: Add Percentage Labels**

First, calculate percentages:

```r
data <- data %>%
  mutate(percentage = count / sum(count) * 100,
         label = paste0(round(percentage, 1), "%"))

print(data)
```

Now, add labels:

```r
ggplot(data, aes(x = "", y = count, fill = category)) +
  geom_bar(stat = "identity", width = 1) +
  coord_polar("y") +
  geom_text(aes(label = label),
            position = position_stack(vjust = 0.5)) +
  labs(title = "Pie Chart with Percentage Labels")
```

---

### **Step 4: Improve Aesthetics**

* Remove axis
* Apply nicer colors

```r
ggplot(data, aes(x = "", y = count, fill = category)) +
  geom_bar(stat = "identity", width = 1, color = "white") +
  coord_polar("y") +
  geom_text(aes(label = label), position = position_stack(vjust = 0.5)) +
  scale_fill_brewer(palette = "Pastel1") +
  theme_void() +  # Removes background, axes, grid
  labs(title = "Refined Pie Chart")
```

---

### **Step 5: Add Legend Title & Customize Theme**

```r
ggplot(data, aes(x = "", y = count, fill = category)) +
  geom_bar(stat = "identity", width = 1, color = "white") +
  coord_polar("y") +
  geom_text(aes(label = label), position = position_stack(vjust = 0.5)) +
  scale_fill_brewer(palette = "Set3", name = "Category") +
  theme_void() +
  theme(
    plot.title = element_text(hjust = 0.5, face = "bold", size = 16),
    legend.title = element_text(face = "bold")
  ) +
  labs(title = "Beautiful Pie Chart")
```

---

### **Optional: Exploded Pie Chart Effect**

If you want to add a "separated" (exploded) effect:

```r
data <- data %>%
  arrange(desc(category)) %>%
  mutate(ypos = cumsum(count) - 0.5 * count)

ggplot(data, aes(x = 1, y = count, fill = category)) +
  geom_bar(stat = "identity", width = 1, color = "white") +
  coord_polar("y") +
  geom_text(aes(y = ypos, label = label)) +
  scale_fill_brewer(palette = "Pastel2", name = "Category") +
  theme_void() +
  labs(title = "Exploded Pie Chart")
```
