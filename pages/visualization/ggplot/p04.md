

# 📊 **Tutorial: Progressive Creation and Refining of a Histogram in R with ggplot2**

We will proceed in stages:

1️⃣ Basic Histogram
2️⃣ Adjust bin width
3️⃣ Customize colors
4️⃣ Add titles and labels
5️⃣ Add density curve
6️⃣ Facet by group (for comparison)

---

## **Step 0 — Load libraries & prepare data**

```r
# Install if not installed
install.packages("ggplot2")

# Load library
library(ggplot2)

# Sample data: Generate random data (Normal distribution)
set.seed(123)
data <- data.frame(values = rnorm(500, mean = 50, sd = 10))
```

---

## **Step 1 — Basic Histogram**

```r
ggplot(data, aes(x = values)) +
  geom_histogram()
```

By default, `ggplot2` chooses the bin width.

---

## **Step 2 — Control Bin Width**

Let's make the bins narrower to see more details.

```r
ggplot(data, aes(x = values)) +
  geom_histogram(binwidth = 2, color = "black", fill = "skyblue")
```

* `binwidth = 2`: Each bin covers 2 units.
* `color`: Outline color.
* `fill`: Fill color of bars.

---

## **Step 3 — Add Titles and Axis Labels**

Adding titles makes the plot more informative.

```r
ggplot(data, aes(x = values)) +
  geom_histogram(binwidth = 2, color = "black", fill = "skyblue") +
  labs(title = "Distribution of Values",
       x = "Value",
       y = "Count")
```

---

## **Step 4 — Add Density Curve for better shape visualization**

Overlay a density curve to visualize the distribution shape.

```r
ggplot(data, aes(x = values)) +
  geom_histogram(aes(y = ..density..), binwidth = 2, color = "black", fill = "skyblue") +
  geom_density(color = "red", size = 1) +
  labs(title = "Histogram with Density Curve",
       x = "Value",
       y = "Density")
```

---

## **Step 5 — Facet by Group (Comparative Histograms)**

Let’s create a grouping variable for demonstration:

```r
# Add a group column
data$group <- ifelse(data$values > 50, "High", "Low")

ggplot(data, aes(x = values, fill = group)) +
  geom_histogram(binwidth = 2, color = "black", position = "identity", alpha = 0.5) +
  facet_wrap(~group) +
  labs(title = "Histogram Faceted by Group",
       x = "Value",
       y = "Count") +
  scale_fill_manual(values = c("High" = "tomato", "Low" = "skyblue"))
```

---

## **Step 6 — Theme Customization**

Finally, make it visually polished using a theme.

```r
ggplot(data, aes(x = values)) +
  geom_histogram(binwidth = 2, color = "black", fill = "skyblue") +
  labs(title = "Final Histogram",
       subtitle = "With custom theme",
       x = "Value",
       y = "Count") +
  theme_minimal(base_size = 14)
```
