

# 📊 **Tutorial: Progressive Creation of a Histogram in R with ggplot2**

## **Step 0 — Load libraries & prepare data**

```r
# Install ggplot2 package if not already installed
install.packages("ggplot2")

# Load ggplot2 library for plotting
library(ggplot2)

# Generate sample data: 500 random numbers from Normal distribution (mean=50, sd=10)
set.seed(123)  # For reproducibility
data <- data.frame(values = rnorm(500, mean = 50, sd = 10))
```

**Explanation:**

* `install.packages("ggplot2")`: Installs the ggplot2 package.
* `library(ggplot2)`: Loads ggplot2 into the session.
* `set.seed(123)`: Sets the seed so results are reproducible.
* `rnorm(500, mean = 50, sd = 10)`: Generates 500 random numbers with specified mean and standard deviation.
* `data.frame(values = ...)`: Creates a dataframe with one column named `values`.

---

## **Step 1 — Basic Histogram**

```r
ggplot(data, aes(x = values)) +
  geom_histogram()
```

**Explanation:**

* `ggplot(data, aes(x = values))`: Initializes a ggplot object using `data` and mapping `values` to x-axis.
* `geom_histogram()`: Adds histogram bars to the plot. By default, `ggplot2` chooses the bin width automatically.

---

## **Step 2 — Control Bin Width**

```r
ggplot(data, aes(x = values)) +
  geom_histogram(binwidth = 2, color = "black", fill = "skyblue")
```

**Explanation:**

* `binwidth = 2`: Sets width of each bin (grouping interval) to 2 units.
* `color = "black"`: Sets outline color of bars to black.
* `fill = "skyblue"`: Fills bars with sky blue color.

---

## **Step 3 — Add Titles and Axis Labels**

```r
ggplot(data, aes(x = values)) +
  geom_histogram(binwidth = 2, color = "black", fill = "skyblue") +
  labs(title = "Distribution of Values",
       x = "Value",
       y = "Count")
```

**Explanation:**

* `labs(...)`: Adds labels to the plot.

  * `title`: Main title of the plot.
  * `x`: Label for x-axis.
  * `y`: Label for y-axis.

---

## **Step 4 — Add Density Curve**

```r
ggplot(data, aes(x = values)) +
  geom_histogram(aes(y = ..density..), binwidth = 2, color = "black", fill = "skyblue") +
  geom_density(color = "red", size = 1) +
  labs(title = "Histogram with Density Curve",
       x = "Value",
       y = "Density")
```

**Explanation:**

* `aes(y = ..density..)`: Scales histogram to density instead of count to match the density curve.
* `geom_density(color = "red", size = 1)`: Adds a smooth density curve over the histogram.

  * `color = "red"`: Density curve color.
  * `size = 1`: Line thickness of density curve.

---

## **Step 5 — Facet by Group (Comparative Histograms)**

First, **create a grouping variable**:

```r
data$group <- ifelse(data$values > 50, "High", "Low")
```

**Explanation:**

* `ifelse(condition, value_if_true, value_if_false)`: Creates a new column where values > 50 are labeled "High", others "Low".

Now, plot faceted histograms:

```r
ggplot(data, aes(x = values, fill = group)) +
  geom_histogram(binwidth = 2, color = "black", position = "identity", alpha = 0.5) +
  facet_wrap(~group) +
  labs(title = "Histogram Faceted by Group",
       x = "Value",
       y = "Count") +
  scale_fill_manual(values = c("High" = "tomato", "Low" = "skyblue"))
```

**Explanation:**

* `fill = group`: Fills bars by group category.
* `position = "identity"`: Overlays the bars directly (instead of stacking them).
* `alpha = 0.5`: Sets transparency level so overlapping bars are visible.
* `facet_wrap(~group)`: Creates separate histograms for each group in separate panels.
* `scale_fill_manual(...)`: Manually sets fill colors for "High" and "Low" groups.

---

## **Step 6 — Theme Customization**

```r
ggplot(data, aes(x = values)) +
  geom_histogram(binwidth = 2, color = "black", fill = "skyblue") +
  labs(title = "Final Histogram",
       subtitle = "With custom theme",
       x = "Value",
       y = "Count") +
  theme_minimal(base_size = 14)
```

**Explanation:**

* `subtitle`: Adds a subtitle below the main title.
* `theme_minimal(base_size = 14)`: Applies a minimal theme with base font size set to 14 for clearer text.

# ✅ **Summary Table of Key Functions**

| Function              | Purpose                         |

| `aes()`               | Map variables to aesthetics     |
| `geom_histogram()`    | Add histogram bars              |
| `binwidth`            | Set width of bins               |
| `color`               | Outline color of bars           |
| `fill`                | Fill color of bars              |
| `labs()`              | Add titles and axis labels      |
| `geom_density()`      | Overlay density curve           |
| `ifelse()`            | Create new categorical variable |
| `facet_wrap()`        | Split plot into facets by group |
| `scale_fill_manual()` | Set manual colors for groups    |
| `theme_minimal()`     | Apply minimal clean theme       |
